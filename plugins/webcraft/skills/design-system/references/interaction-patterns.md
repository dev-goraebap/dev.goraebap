# 입력과 상호작용

어떤 상호작용을 어느 표면에서 할지 정합니다. 개별 도구의 동작은 [검색·필터·표시](search-filter.md), 대화상자의 배치는 [공통 다이얼로그](dialog.md), 제목·본문 작성은 [생성 양식](creation-form.md)이 소유합니다.

## 표면 고르기

| 하는 일 | 데스크톱 | 휴대폰 |
| --- | --- | --- |
| 값 하나 고르기·짧은 동작 메뉴 | 팝오버 | 바텀시트 |
| 되돌리기 어려운 확인 | 확인 창 | 확인 창(버튼 세로) |
| 몇 칸의 변경 | 짧은 양식 대화상자 | 전체 화면 대화상자 |
| 제목·본문 작성 | 목록 위 대화상자(자기 주소) | 페이지 |
| 읽는 대상 | 자기 페이지 | 자기 페이지 |
| 목록을 보며 항목을 차례로 훑기 | [미리보기 패널](peek.md)(목록 옆, `?peek=`) | 페이지 |
| 행 하나의 사실 확인 | 옆 패널 | 바텀시트 |

## 누르는 대상

행·카드 전체를 누르면 그 대상을 엽니다. 행 안의 링크·사람·별·메뉴는 행을 열지 않고 자기 동작을 합니다. 화면 이동은 링크(`href`)로 해 새 탭·주소 복사가 되게 합니다. 펼치기·별처럼 행 안의 버튼은 행 링크로 번지지 않게 합니다.

페이지를 대화상자에서도 쓰도록 바꿀 때 행 전체의 링크를 제목 텍스트 링크로 줄이지 않습니다. 행의 빈 곳과 설명·아이콘을 눌러 같은 대상으로 열리는지 확인하고, 행 안의 별도 동작은 구분합니다.

## 선택 칸

작은 고정 선택지는 Selector, 큰 목록에서 찾는 입력은 검색이 있는 고르기(처음 8개·최대 50개)입니다. 검색을 열면 입력에 초점을 두고, 고른 뒤나 Esc 뒤에는 열었던 칸으로 초점을 돌립니다. 검색 중에 보이지 않는 선택 항목도 지킵니다. 대기·결과 없음·추가 결과 안내를 구분합니다.

날짜는 공통 달력 하나를 쓰고, 시간은 직접 입력과 목록을 함께 줍니다. 종료 시각은 시작 이후의 값과 길이를 함께 보입니다. 입력 방식은 창 폭으로 정해 터치 노트북에서도 데스크톱 배치가 깨지지 않게 합니다.

## 키보드

| 키 | 동작 |
| --- | --- |
| Esc | 열린 메뉴·검색·대화상자를 닫고 연 요소로 초점을 돌립니다 |
| Ctrl/⌘+Enter | 작성 양식 제출 |
| Enter | 짧은 양식의 한 줄 칸 제출 |
| Ctrl/⌘+S | 명시 저장을 고른 본문 편집의 저장 |

모든 단축키는 한글 조합 중(`isComposing`)에는 무시하고, 입력 칸에 초점이 있을 때 페이지 전역 단축키를 실행하지 않습니다.

## 순서 바꾸기

같은 목록 안의 순서는 손잡이 끌기와 키보드(Alt+↑/↓)를 함께 줍니다. Esc로 취소하고, 이동할 때마다 위치를 읽어 주며, 실패하면 원래 순서로 돌립니다. 트리는 어느 부모 안에서 옮길 수 있는지를 먼저 정합니다. 위·아래 메뉴로 대신하지 않습니다.
