# 모션

움직임은 위치가 바뀌었거나 새 내용이 도착했음을 알릴 때, 또는 절차 완료를 한 번 축하할 때만 씁니다. 장식으로 반복하는 움직임을 두지 않습니다.

| 쓰임 | 시간 |
| --- | --- |
| 꺾쇠 회전·작은 상태 전환 | 빠름 토큰(100ms) |
| 메뉴·시트 등장 | 중간 토큰(250ms) 또는 부품 기본값 |
| 상태 화면 문구가 자리 잡기 | 420ms, `cubic-bezier(0.2, 0, 0, 1)` |
| 상태 그림이 도착해 나타나기 | 600ms, 한 번만 |
| 화면 전환(캐시가 있을 때) | 200ms 교차 페이드 |
| 첫 방문 덮개 걷기 | 최소 0.3초 보인 뒤 700ms 페이드([데이터 상태](data-states.md)의 첫 화면) |

이미 본 그림·내용은 다시 흐리게 시작하지 않습니다. 흐림(blur) 전환은 매 프레임 다시 그려 무거우므로 쓰지 않습니다.

## 화면 전환

화면 전환은 View Transitions로 합니다. 지원하지 않는 브라우저와 동작 줄이기 설정에서는 전환 없이 바로 바꿉니다. 페이지 사이 전환의 범위와 시간은 [데이터 상태](data-states.md#화면을-바꾸는-동안)를 따릅니다.

- 둥근 면(본문 카드, 휴대폰 하단 막대)이 전환할 때 스냅숏이 각진 사각형으로 번쩍이지 않게, 그 면의 전환 묶음(`::view-transition-image-pair`)을 면의 모서리 반지름으로 자릅니다.
- 대화상자의 바꿔 끼우기(불러오는 중 → 내용, 대화상자 → 대화상자)는 View Transitions로 두 내용을 겹쳐 바꿉니다. 이 전환 동안 페이지 콘텐츠에는 전환 이름을 두지 않습니다. 같이 잡히면 대화상자가 다시 뜨는 것처럼 보입니다.
- 대화상자의 "페이지로 열기"는 대화상자가 그 자리에서 페이지의 콘텐츠 영역으로 커지는 공유 요소(shared element) 전환입니다. 같은 전환 이름이 동시에 두 요소에 붙지 않게, 이름은 전환 종류(`types`)가 맞을 때만 붙입니다.

## 완료 축하

신청 제출이나 최종 승인, 초기 설정 완료처럼 사용자의 절차가 성공으로 끝난 순간에는 기준 요소에서 한 번 터져 사라지는 색종이 효과를 더할 수 있습니다. 키트에는 없습니다. 이 효과는 화면의 완료 상태 확정·안내 문구를 대신하지 않는 별개 장식이며, 실패·반려·취소에는 쓰지 않습니다.

## 동작 줄이기

`prefers-reduced-motion: reduce`이면 이동·등장·회전·화면 전환을 끄고 결과 상태를 바로 보입니다. 완료 축하 효과도 실행하지 않고 생략합니다. CSS 전환을 더하면 같은 파일에 줄이기 규칙도 둡니다. 스크립트에서 부드러운 스크롤·애니메이션을 시작할 때도 같은 설정을 확인합니다.

화면 전환과 데이터 대기의 기준은 [데이터 상태](data-states.md)를 따릅니다.
