# 아이콘

아이콘은 명령·상태·대상을 구분하는 시각 언어입니다. 아이콘은 한 세트에서 고르고, 같은 아이콘의 선 형태와 채운 형태를 함께 가진 세트를 씁니다. 화면은 아이콘 세트를 직접 가져오지 않고 공통 아이콘 모듈에서 뜻을 나타내는 이름(검색, 왼쪽 화살표, 달력)으로 부릅니다. 이름에서 실제 아이콘으로 가는 매핑은 한 곳에 두고, 사용하는 이름만 만듭니다. 그래야 아이콘을 바꿀 때 화면 코드를 고치지 않고 매핑 한 곳만 고칩니다.

## 기본과 선택

기본은 선 형태, 고름·열림·눌림·현재 위치는 같은 아이콘의 채운 두 톤 형태(이하 선택 형태)입니다. 선택 여부는 아이콘을 부를 때 속성 하나로 넘깁니다. 사이드바의 현재 항목, 하단 막대, 켜진 도구, 열린 메뉴(…), 고른 뷰가 모두 같은 규칙을 따릅니다. 기본·선택 비교는 같은 의미 이름으로 확인합니다.

## 크기와 정렬

데스크톱의 13px 본문 옆 아이콘은 16px(약 1.2배)에서 출발하며 칩 안은 14px입니다. 모바일 헤더·툴바·시트의 닫기와 뒤로가기는 24px, 메뉴·선택 목록의 아이콘은 20px입니다. 하단 막대은 24px입니다. 16px 루트에서는 글자 옆 아이콘의 잉크가 약 0.5px 낮게 보여 반 픽셀 올리고, 루트가 커지는 1920px 이상에서는 보정을 멈춥니다. 컴포넌트마다 별도의 이동값을 누적하지 않습니다.

모바일에서 아이콘 버튼의 누르는 영역은 최소 44px입니다. 프로필 그림은 28~32px로 두고 그 바깥에서 같은 누르는 영역을 확보합니다. 누르는 영역을 넓히려고 그림을 44~48px로 키우지 않습니다. 반대로 버튼 상자만 넓히고 안의 아이콘을 데스크톱 크기에 두지도 않습니다. 컴포넌트가 아이콘 칸을 고정하면 SVG가 줄어들지 않는지 실제 크기와 중심을 확인합니다. 헤더의 아이콘 규칙이 그 안에서 열리는 시트·메뉴까지 번지지 않도록 범위를 제한합니다.

속성 열·활동 기록처럼 아이콘이 세로로 늘어선 곳은 상자 크기뿐 아니라 24 격자 위에 그려진 범위도 비슷하게 맞춥니다(대부분 20칸 안팎). 범위가 눈에 띄게 작은 아이콘(16칸 정도)은 키우지 않고 같은 세트에서 같은 뜻의 다른 아이콘으로 바꿉니다. 키우면 선도 굵어지기 때문입니다. 확인은 화면에서 SVG의 `getBBox()`를 재서 합니다. 기본 상태의 줄에 일부 선이 흐린 두 톤 선 형태를 섞지 않습니다. 같은 색이어도 흐리고 작게 보입니다.

## 고르는 기준

| 상황 | 아이콘 |

| 화면에서 나가는 뒤로(헤더·시트·필터 단계) | 왼쪽 화살표(←) |
| 날짜·단계의 이전·다음, 경로 구분 | 왼쪽·오른쪽 꺾쇠 |
| 날짜·기간·수정일 | 달력 |
| 닫기·지우기 | × |
| 더 많은 동작 | 말줄임(…) |
| 만들기 | 더하기(+) |

장식 아이콘은 접근성 트리에서 숨깁니다. 아이콘만 있는 버튼에는 접근 가능한 이름과 툴팁을 줍니다. 아이콘만으로 뜻을 알아보기 어려우면 이름을 함께 보입니다. 상태 차이를 색만으로 표현하지 않습니다.
