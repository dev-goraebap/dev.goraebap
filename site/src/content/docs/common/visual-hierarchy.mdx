화면 유형(앱 셸, 랜딩, 문서 사이트)과 관계없이 화면을 만들거나 검토할 때 공통으로 적용하는 시각 위계, 간격, 면과 선, 색의 규칙이다. 각 항목의 `[관례]`, `[고래밥]`, `[선호]` 표시는 규칙의 성격을 나타내며, 구분 기준은 [읽는 법](/start/how-to-read/)을 따른다.

## 위계는 덜 중요한 것을 누그러뜨려 만든다

- **[관례]** 중요한 요소를 더 크고 굵고 화려하게 강조하기보다, 덜 중요한 요소의 글자색을 보조 색으로 낮추거나 글자 크기를 줄여 주인공이 자연스럽게 드러나게 한다([Refactoring UI](https://www.refactoringui.com/), 원문 본문은 미확인이며 요약 기준).
- **[관례]** 같은 원리로 탐색 영역(사이드바)은 본문보다 한 단계 뒤로 물러난 면(본문보다 어둡거나 바탕에 가까운 면)으로 두어 본문이 시각의 중심이 되게 한다([Linear 디자인 리프레시](https://linear.app/now/behind-the-latest-design-refresh), [셸과 사이드바](/app-shell/shell-and-sidebar/)).

## 상자를 줄이고 여백과 정렬로 먼저 묶는다

**[관례]** 관련된 요소를 묶거나 구역을 나눌 때 처음부터 모든 것을 카드나 테두리로 감싸지 않는다([Refactoring UI](https://www.refactoringui.com/), 원문 미확인·요약 기준). 화면에 상자가 많아질수록 실제 내용보다 테두리가 먼저 눈에 띄기 때문이다. 묶음을 나눌 때는 아래 순서로 판단한다.

1. **여백과 정렬**: 먼저 요소 사이의 간격과 정렬선만으로 묶음이 구분되는지 확인한다.
2. **선(구분선)**: 여백만으로 경계가 모호할 때만 사이에 선을 넣는다.
3. **면(카드)**: 독립된 묶음을 주변과 분리해 드러내야 할 때만 배경 면이나 카드를 쓴다. 예를 들어 목록의 개별 행은 카드로 감싸지 않고, 설정 화면처럼 항목 수가 적은 이름-값 묶음에만 카드를 쓴다([콘텐츠 폭](/app-shell/content-width/), [컬렉션](/app-shell/collections/)).

## 간격은 정해진 단계만 쓴다

**[관례]** 요소 사이의 여백과 안쪽 여백은 임의의 픽셀 값을 쓰지 않고 `4·8·12·16·24·32…`처럼 정해진 단계만 고른다. 처음 배치할 때는 여백을 넉넉하게 잡고 정해진 단계 안에서 줄이거나 늘린다.

8px 기반 간격 체계([Atlassian Spacing](https://atlassian.design/foundations/spacing))에 따라 용도별로 아래 범위를 쓴다.

| 범위 | 쓰는 곳 |
| --- | --- |
| `0~8px` | 촘촘한 UI. 아이콘과 라벨 사이, 나란히 붙는 도구 버튼 사이 등 한 묶음 안의 밀착된 요소 |
| `12~24px` | 부품 안쪽 여백과 부품 내부의 하위 요소 사이 |
| `32px 이상` (`32~80px`) | 페이지 단위의 큰 구역 사이나 화면 바깥 여백 |

## 시각 소음을 줄이고 색은 의미에만 쓴다

- **[관례]** 장식용 아이콘, 불필요한 구분선, 색 배경을 덜어내 시각 소음을 낮춘다. 한 화면에 많은 정보가 들어가는 업무 도구에서도 화면이 복잡해 보이지 않게 하기 위해서다([Linear 디자인 리프레시](https://linear.app/now/behind-the-latest-design-refresh)).
- **[관례]** 유채색은 상태(정상, 주의, 오류, 진행 등)나 데이터 분류처럼 분명한 의미가 있을 때만 쓴다. 장식 목적으로 배경이나 테두리에 색을 넣지 않는다.
  - 참고 사례로 [Linear UI 재설계](https://linear.app/now/how-we-redesigned-the-linear-ui)에서는 따뜻한 회색 바탕을 기본으로 삼고, 테마 색 변수를 98개에서 3개(`base`, `accent`, `contrast`)로 줄여 LCH 색 공간에서 나머지 표면과 글자색을 계산했다. (단, Linear 화면의 실제 픽셀 수치는 공개 자료에 없어 확인하지 못했다.)
- 아이콘 사용과 상태 표현 방식은 [아이콘](/common/icons/)에서 다룬다.

## 바탕·면·선·강조색의 기본 모양

기능 계약이 아니라 기본 시각 취향으로 정한 모양이다. 취향이 바뀌면 기능 규칙을 건드리지 않고 바꿀 수 있다(적용된 모습은 [선호 화면](/app-shell/preferred-screens/) 참고).

- **[선호] 먹색 강조**: 별도의 브랜드 원색을 강조색으로 쓰지 않고 본문 글자와 같은 먹색을 주 강조색으로 쓴다.
- **[선호] 차분한 회색 바탕과 4단계 면**: 바탕은 차분한 회색으로 두고, 시각 높이에 따라 **바닥 → 페이지 → 카드 → 떠 있는 면**(팝오버·대화상자 등)의 4단계 면만 쓴다.
- **[선호] 2단계 선**: 선은 구역 안의 항목을 가볍게 나누는 **내부선**과 영역의 테두리를 잡아 주는 **바깥 경계** 두 단계만 쓴다.
