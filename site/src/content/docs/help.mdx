## 문제가 생겼을 때

| 이럴 때 | 이렇게 해 보세요 |
| :--- | :--- |
| 에이전트가 Webcraft 규칙을 안 따르는 것 같아요 | 새 세션을 열고 "Webcraft 연결돼 있는지 확인해 줘"라고 물어보세요. |
| 플러그인이 오래된 판이라고 나와요 | [업데이트](/getting-started/#업데이트)한 뒤 새 세션을 여세요. |
| 키트 부품을 받았더니 오류가 나요 | 에이전트에게 오류 메시지를 보여 주고 고쳐 달라고 하세요. |

## 규칙을 제안하고 싶을 때

쓰다 보니 다른 프로젝트에도 맞을 것 같은 규칙이 생기면 에이전트에게 말해 주세요.

```text
이 규칙 Webcraft에 제안해 줘.
```

에이전트가 제안서를 써서 [Webcraft 저장소](https://github.com/dev-goraebap/dev.goraebap/issues)에 이슈로 올려요.
