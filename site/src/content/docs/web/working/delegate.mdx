평소처럼 하고 싶은 일을 말하면 돼요. 특별한 명령은 없어요.

```text
이슈 목록에 담당자 필터 추가해 줘.
```

```text
저장 버튼을 눌러도 목록이 안 바뀌어. 고쳐 줘.
```

```text
인증 관련 코드를 별도 모듈로 나눠 줘.
```

## 선택이 필요할 때

방법이 여러 가지라 결과가 달라지는 일은 에이전트가 혼자 정하지 않고 물어봐요. 고를 수 있는 안 두세 개와 추천하는 안, 각각 감수할 점을 함께 보여 줘요. 마음에 드는 걸 고르면 그대로 진행해요.

## 끝나면 받는 것

작업이 끝나면 무엇을 바꿨는지, 어떤 검사를 돌렸는지, 화면에서 직접 확인한 것과 확인하지 못한 것을 나눠서 알려 줘요.

커밋, 푸시, 배포는 부탁할 때만 해요.
