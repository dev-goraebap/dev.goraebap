만들 제품이 정해졌다면 에이전트에게 프로젝트를 만들어 달라고 하세요.

```text
Webcraft로 새 프로젝트 만들어 줘. 이름은 my-product야.
```

## 만드는 동안 묻는 것

에이전트가 프로젝트를 어디에 만들지 물어요.

- 지금 폴더에 만들기
- 새 폴더를 만들어서 그 안에 만들기
- 직접 만들어 둔 폴더 알려 주기

이미 빈 프로젝트 폴더에서 시작했다면 그 자리를 써요.

## 만들어지는 것

| 위치 | 들어 있는 것 |
| :--- | :--- |
| `client/` | 바로 실행되는 React 앱 |
| `server/` | 바로 실행되는 Spring Boot 서버 |
| `AGENTS.md` | 이 프로젝트가 Webcraft를 따른다는 안내 |
| `CLAUDE.md` | Claude Code가 `AGENTS.md`를 읽게 하는 한 줄 |

다 만들어지면 에이전트가 앱과 서버를 한 번씩 띄워서 동작하는지 보여 줘요. 그다음부터는 [Webcraft로 일하기](/working/)처럼 기능을 하나씩 부탁하면 돼요.
