아이콘은 화면에서 명령·상태·대상을 구분하는 시각 언어입니다. 앱 셸과 각 화면에서 아이콘을 고르고 배치할 때 이 규칙을 따릅니다. 개발자와 에이전트는 새 화면을 만들거나 검토할 때 어떤 아이콘을 어떤 크기와 상태로 둘지 이 기준으로 판단합니다.

규칙마다 성격을 표시합니다. **[관례]**는 여러 제품과 지침이 수렴한 기준, **[고래밥]**은 관례가 없거나 우리가 따로 정한 결정과 이유, **[선호]**는 취향으로 고른 모양입니다([읽는 법](/start/how-to-read/) 참고).

## 한 세트만 쓰고 의미 이름으로 부른다

- **[관례]** 아이콘 수를 줄여 화면 소음을 낮춥니다([시각 위계](/common/visual-hierarchy/)). 글자만으로 뜻이 분명한 곳에는 아이콘을 덧붙이지 않습니다.
- **[선호]** 앱 전체에서 아이콘은 한 세트만 씁니다. 기본 세트는 Solar 아이콘(480 Design, CC BY 4.0)입니다. Linear는 아이콘을 자체 제작하지만 우리는 공개 세트인 Solar를 택했습니다. 나중에 다른 세트로 바꾸더라도 "한 세트만 쓰고, 의미 이름으로 부르며, 선과 채움으로 상태를 표현한다"는 규칙은 그대로 유지합니다.
- **[고래밥]** 화면과 부품에서는 아이콘 모양이나 세트 고유 이름 대신 역할에 따른 의미 이름(`search`, `back`, `layout-list`)으로 부릅니다. 의미 이름에서 실제 아이콘으로 연결하는 매핑은 생성 스크립트 한 곳에만 두고, 실제로 쓰는 이름만 생성합니다. 새 아이콘이 필요하면 매핑에 이름을 더하고 다시 생성합니다. 이렇게 해 두면 화면 코드를 건드리지 않고 아이콘 세트를 바꾸거나 모양을 교체할 수 있습니다.

## 기본은 선, 선택과 활성은 채움으로 구분한다

- **[선호]** 기본 상태는 선(Linear 스타일) 모양을 쓰고, 고름·열림·눌림·현재 위치는 같은 아이콘의 채운 모양(Bold Duotone)을 씁니다.
- **[고래밥]** 상태 변화는 모든 자리에서 같은 규칙을 따릅니다. [사이드바](/app-shell/shell-and-sidebar/)의 현재 메뉴 항목, [휴대폰 하단 탭](/app-shell/adaptive/), [머리 줄과 툴바](/app-shell/header-and-toolbar/)의 켜진 도구 버튼, 열린 메뉴(`…`), 고른 뷰 버튼 모두 평소에는 선 모양이고 활성화되면 채운 모양으로 바뀝니다. 새 의미 이름을 더할 때는 기본 모양과 채운 모양을 나란히 놓고 같은 대상으로 보이는지 확인합니다.
- **[관례]** 상태 차이를 색만으로 표현하지 않습니다. 선에서 채움으로 바뀌는 모양 변화나 모서리 점 표시 등을 함께 써서 색을 구분하기 어려운 사용자도 상태를 알아볼 수 있게 합니다.

## 상황별 아이콘 선택 기준

화살표와 기호는 이동 성격에 따라 구분해 씁니다.

| 상황 | 의미 이름과 모양 | 구분 이유 |
| --- | --- | --- |
| 화면에서 나가는 뒤로 (머리 줄 상위 이동, 바텀시트, 필터 단계 복귀) | `back` (왼쪽 화살표 `←`) | 현재 맥락을 빠져나와 이전 화면이나 상위 단계로 돌아가는 동작임을 분명히 합니다 **[고래밥]** |
| 날짜·단계의 이전과 다음, 경로(Breadcrumb) 구분 | `previous` · `forward` (꺾쇠) | 같은 화면 안에서 순서나 기간을 넘기거나 계층 사이를 가르는 기호입니다 **[관례]** |
| 창·시트 닫기, 입력값·필터 지우기 | `close` | 현재 열린 면을 닫거나 값을 비웁니다 **[관례]** |
| 자리에서 다 보여 주지 못하는 추가 동작 | `more` (`…`) | 보조 메뉴를 엽니다 **[관례]** |
| 새 항목 만들기 | `plus` | 작성 동작을 나타냅니다 **[관례]** |
| 권한·보호 설정 | `shield` | 보안이나 접근 제어 대상을 나타냅니다 **[고래밥]** |

## 크기와 글자 정렬

아이콘 크기는 함께 놓이는 글자 크기와 자리의 역할에 맞춥니다. (Linear 실제 화면의 아이콘 픽셀 수치는 공개 자료에 없어 확인하지 못했습니다. 아래 값은 우리 화면 기준입니다.)

| 자리 | 아이콘 크기 | 기준과 이유 |
| --- | --- | --- |
| 본문·메뉴·버튼 글자(데스크톱 13px, 휴대폰 15px) 옆 | 16px | 글자 크기의 약 1.2배에서 출발해 한 줄 높이와 균형을 맞춥니다 **[고래밥]** |
| 휴대폰 하단 탭·만들기 FAB | 24px | 터치 대상 안에서 라벨과 함께 멀리서도 구분되게 합니다 **[고래밥]** |
| 알약(작은 칩·배지) 안 | 14px | 좁은 높이에 맞춰 본문 옆 아이콘보다 한 단계 줄입니다 **[고래밥]** |

- **[고래밥]** 루트 글자 크기가 16px인 환경에서는 글자 옆 아이콘의 잉크 중심이 글자보다 약 0.5px 낮게 보여 반 픽셀 위로 올리고, 루트 글자 크기가 커지는 1920px 이상 화면에서는 보정을 멈춥니다. 이 정렬 보정은 공통 아이콘 규칙 한 곳에서만 처리하고, 개별 부품마다 따로 이동값을 누적하지 않습니다.

## 접근성과 라벨 표시

- **[관례]** 글자 바로 옆에서 뜻을 보조하는 장식 아이콘은 접근성 트리에서 숨깁니다.
- **[관례]** 글자 없이 아이콘만 있는 버튼(도구 버튼, 닫기 버튼, 더보기 버튼)에는 스크린 리더가 읽을 접근 가능한 이름(`label`)과 포인터를 올렸을 때 보이는 툴팁을 반드시 함께 둡니다.
- **[관례]** 아이콘 모양만으로 뜻을 바로 알아보기 어려운 동작에는 아이콘만 두지 않고 글자 이름을 함께 보입니다.
