셸 없는 인증 화면을 만들 때 본뜹니다. 데스크톱의 하늘·움직이는 구름 CSS 배경 위 가운데 카드와 휴대폰의 배경 없는 전체 화면에 같은 사이트 브랜드를 두고, 칸 곁에 표시하는 빈 칸 안내, 어느 칸이 틀렸는지 밝히지 않고 제출 버튼 바로 위에 알리는 서버 자격 오류, 로그인·비밀번호 찾기·회원가입·이메일 인증 코드(6자리) 흐름을 다룹니다. 모의 인증으로 동작하며 실제 메일은 보내지 않되, 화면 안에는 제작·기술 상태 문구를 반복해 적지 않습니다.
