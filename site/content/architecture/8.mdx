arc42의 8절은 특정 모듈 하나에 머물지 않고 여러 구성 요소에 걸쳐 일관되게 적용하는 공통 규칙과 해법을 다룹니다. Webcraft의 상세 지침과 화면 해설은 대부분 이 절에 속하며, 메뉴를 백엔드·프론트엔드로 먼저 가르지 않고 8.1부터 8.9까지의 아키텍처 주제로 묶습니다.

API와 모듈 계약(8.1), 백엔드 코드(8.2), 데이터와 마이그레이션(8.3)은 서버와 데이터 경계의 규칙을 다루고, 프론트 코드와 상태(8.4), 화면 기초(8.5), 화면 배치와 탐색(8.6), 데이터 상태와 입력(8.7), UI 부품 사용(8.8)은 클라이언트 코드와 화면 표현을 다룹니다. 변경에 맞는 확인 절차는 검증(8.9)에 모으고, 프로젝트마다 다르게 적용하는 예외는 `AGENTS.md`의 프로젝트 규칙 표에 적습니다.
