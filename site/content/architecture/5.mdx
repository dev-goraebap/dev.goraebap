arc42의 5절은 시스템을 이루는 정적 구성 요소와 책임, 의존 방향을 다룹니다. Webcraft에서 프론트엔드는 Feature-Sliced Design(FSD)의 계층·슬라이스·공개 API 규칙으로 코드를 나누고, 화면 바깥 틀은 앱 셸 하나로 사이드바·페이지 머리 줄·휴대폰 하단 탭을 조립합니다. 백엔드는 단수 이름의 업무 모듈로 나누며, 각 모듈 안을 `application`·`domain`·`infrastructure` 계층으로 가르고 모듈 루트의 `Facade`·`Spi`·`Event`만 모듈 간 공개 계약으로 둡니다.

어떤 업무 모듈과 프론트엔드 슬라이스를 둘지, 메뉴 공간과 하위 묶음을 어떻게 구성할지는 프로젝트의 도메인에 따라 정합니다.
