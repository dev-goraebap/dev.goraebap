arc42 8절의 하위 절로, 코드나 문서를 바꿨을 때 변경 종류와 위험에 맞춰 확인해야 할 검증 기준을 다룹니다. Webcraft는 화면·반응형·서버 로직·API 계약·스키마·스킬 문서별 필수 확인 항목과, 화면 전환·캐시·지연 로딩 변경 시 주요 이동 경로의 레이아웃 이동 합(`layout-shift` 0.01 이하)·재방문 진행 표시 미노출·`aria-busy` 해제 대기를 재는 Playwright 점검 절차를 정합니다. 프로젝트는 실제 검사 스크립트와 CI 명령, 개발용 로그인 경로를 정하며, 완료 보고에서는 수행한 검증과 확인하지 못한 범위를 구분합니다.
