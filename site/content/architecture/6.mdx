arc42의 6절은 주요 시나리오에서 구성 요소들이 실행 중에 상호작용하는 동적 흐름을 다룹니다. 프론트엔드는 링크에 포인터나 초점이 올 때 다음 화면의 데이터와 지연 로딩 코드를 미리 준비하고, 캐시가 있으면 즉시 그린 뒤 뒤에서 갱신하며, 대기가 150ms를 넘을 때만 콘텐츠 카드 위쪽 테두리에 진행 표시를 띄웁니다. 작성·수정 양식을 데스크톱 목록 위에서 열 때는 라우트 마스킹으로 목록 맥락을 유지한 채 양식의 주소를 노출하고, 백엔드에서는 요청이 Controller에서 피처별 Service로 들어가 읽기는 조회 포트로, 쓰기는 도메인 엔티티 복원·업무 메서드 호출·명시적 저장으로 흐릅니다.

프로젝트는 개별 유스케이스의 트랜잭션 범위와 외부 후속 작업(영속 outbox 등), 화면별 검색 조건과 복귀 경로를 정합니다.
