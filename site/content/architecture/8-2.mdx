arc42 8절의 하위 절로, 백엔드 모듈 안에서 도메인·서비스·저장소·조회 포트를 작성하는 공통 코드 규칙을 다룹니다. Webcraft는 피처별 `Service` 하나에 읽기와 쓰기를 함께 두되 읽기는 `Query` 포트와 jOOQ 구현으로, 쓰기는 순수 Java 도메인 엔티티의 업무 메서드와 명시적 `save`로 경로를 나누며, 도메인 규칙 위반(`DomainRuleViolation`)과 서비스 유스케이스 오류(`BusinessException`·`ErrorCode`)의 판정 책임을 분리합니다. 프로젝트는 패키지 루트와 실제 애그리거트·피처 구분, 정적 검사·포매터 도구를 정합니다.
