arc42 8절의 하위 절로, 데이터 대기·빈 결과·오류 상태의 피드백과 사용자의 입력·검색·작성 상호작용 규칙을 다룹니다. Webcraft는 첫 방문 덮개와 화면 전환 중 진행 표시·교차 페이드, 대기·실패·404·0건의 상태 화면 순서와 오류 알림 자리(칸 곁·배너·되돌리기 토스트), 상호작용 표면 선택과 키보드 단축키, 목록의 검색·필터·표시 도구, 제목·본문·속성 알약으로 이루어진 생성 양식과 초안 보존, 화면 문구 작성과 UI 검증 기준을 정합니다. 프로젝트는 실제 필터 속성·선택지 한도, 본문 편집기의 명시·자동 저장 정책과 활동 영역의 댓글 기능을 정합니다.
