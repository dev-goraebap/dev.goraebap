arc42 8절의 하위 절로, 프론트엔드 컴포넌트·훅 작성과 비동기 데이터·라우트·초안 상태의 흐름을 다룹니다. Webcraft는 서버 데이터는 TanStack Query, 확정된 필터·정렬·페이지는 검증한 URL, 입력 초안은 로컬 상태나 라우터 위의 초안 저장소가 소유하도록 나누고, 파생값 state 복사 금지와 라우트 loader·프리페치·캐시 수명 기준을 정합니다. 프로젝트는 라우트 경로와 API 엔드포인트, 연속 저장·충돌 해결의 세부 정책을 정합니다.
