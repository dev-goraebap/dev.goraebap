에이전트가 무엇을 기준으로 작업하는지 궁금할 때 읽어 보세요. 규칙을 외울 필요는 없어요. 에이전트가 작업할 때 알아서 찾아 읽어요.

| 영역 | 다루는 것 |
| :--- | :--- |
| [작업 방식](/rules/goraebap-mode/) | 일을 나누고, 확인하고, 보고하는 방법 |
| [프론트엔드](/rules/frontend/) | 폴더 구조, 화면 사이 이동, 서버 데이터와 작성 중인 내용 다루기 |
| [디자인 시스템](/rules/design-system/) | 색, 간격, 부품 고르기, 화면 배치, 휴대폰 화면 |
| [백엔드](/rules/backend/) | 모듈 나누기, 서비스와 저장소 |
| [API](/rules/api/) | 요청과 응답, 오류, 권한 |
| [데이터베이스](/rules/database/) | 테이블 바꾸기, 데이터 옮기기 |
| [아키텍처](/rules/architecture/) | 큰 구조를 바꾸거나 새 기술을 들일 때 |
