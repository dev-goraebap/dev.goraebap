Webcraft 플러그인의 개발 지침을 사람이 읽도록 모은 사이트입니다. 지침 문서는 플러그인의 스킬 Markdown을 그대로 보여 주므로 플러그인을 고치면 사이트도 바뀝니다. 화면 해설은 그 규칙을 사람이 읽도록 풀어 쓴 글이며, 둘이 다르면 스킬이 맞습니다.

규칙은 아키텍처에서 찾고, 규칙대로 만든 부품과 실행 견본은 UI 키트에서 찾습니다.

- 소개에는 이 안내와 [작업 방식](/rules/goraebap-mode/), [프로젝트 연결](/rules/manage-workflow/)이 있습니다.
- 아키텍처에는 [arc42 1~9절](/architecture/1/) 순서로 개발 지침과 화면 해설을 절마다 모아 두었습니다.
- UI 키트에는 Foundations·Primitives·Composites·Layouts·Patterns 부품과 기능 단위 실행 견본인 [Playground](/catalog/playground/)가 있습니다.

## 규칙의 세 가지 표시

| 표시 | 뜻 | 바꿀 때 |
| --- | --- | --- |
| `[관례]` | 여러 제품과 디자인 지침이 같은 방향으로 수렴한 규칙입니다. 근거 링크가 있습니다. | 근거가 바뀌었을 때 |
| `[고래밥]` | 뚜렷한 관례가 없거나 관례와 다르게 정한 우리 결정입니다. 선택 이유와 감수하는 대가를 함께 적습니다. | 결정 당시의 이유가 더 이상 맞지 않을 때 |
| `[선호]` | 사용자 취향으로 고른 시각적 모양입니다. 기능이나 사용성 규칙이 아닙니다. | 취향이 바뀌면 자유롭게 |
