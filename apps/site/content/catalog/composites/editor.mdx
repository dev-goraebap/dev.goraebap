본문 칸을 넓힌 리치 에디터(Tiptap 3)입니다. 읽기와 편집이 같은 에디터이고, 편집할 때 블록 손잡이·블록 메뉴·`/` 명령·선택 서식 도구·표 도구·올리는 칸이 붙습니다. 제목은 화면의 시스템 제목 하나이고 본문 제목은 2단계부터입니다. 올리기와 링크 미리보기는 호스트가 비동기 함수로 넘기며, 견본은 blob 주소와 정해 둔 답을 쓰는 가짜 호스트입니다.

## 단축키

| 동작 | 키 |
| --- | --- |
| 고른 블록 복제 · 복사 | Ctrl/⌘ + D · Ctrl/⌘ + C |
| 고른 블록 위·아래로 옮기기 | Alt + ↑ · Alt + ↓ |
| 고른 블록 지우기 | Delete |
| 블록 넣기 | `/` 다음 이름, ↑·↓, Enter, Esc |
| 올리는 칸 닫기 | ✕ 또는 Esc |
| 수정 화면 저장 | Ctrl/⌘ + S |
