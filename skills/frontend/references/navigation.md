# 화면 전환

첫 화면에 필요한 조회는 라우트 loader에서 준비하고 컴포넌트와 캐시를 공유한다. 메뉴·링크 진입, 뒤로 돌아오기, 검색 조건 변경을 구분해 로딩·스크롤·캐시 정책을 정한다.

- 검색 조건과 탭은 검증한 URL에서 읽는다. 입력 중 검색은 replace, 사용자가 구분해서 돌아올 이동은 push를 기본으로 삼는다.
- 뒤로 돌아온 목록은 가능한 한 읽던 위치와 로드한 행을 유지한다. 새로 진입할 때의 최신성 정책과 섞지 않는다.
- 전체 페이지와 상세 패널이 같은 대상을 열면 조회와 실제 화면 부품을 공유한다. 데모·플레이그라운드도 제품 부품에 가짜 데이터만 연결한다.
- 반응형 메뉴·뒤로가기·닫기, 포커스와 Esc 동작을 확인한다. 모달과 페이지의 이탈 시 저장되지 않은 초안 처리도 정한다.
