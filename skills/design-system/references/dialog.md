# 공통 다이얼로그

헤더·스크롤 본문·푸터를 한 조합으로 사용한다. 기본 레퍼런스는 좌우와 바깥쪽 안 여백 1rem, 헤더 아래와 본문 위 각각 0.5rem이다. 위치는 프로젝트가 정하며 이 레퍼런스는 위·아래에 같은 최소 여유가 남도록 12dvh를 기준으로 제한한다. 긴 본문에서도 제목, 닫기와 마지막 동작에 닿아야 한다.

구분선은 푸터의 위쪽 경계에 선택적으로 둔다. 확인·소수 설정은 대화상자, 주소가 필요한 긴 작성은 페이지와 같은 양식을 공유하는 패널로 구성한다.

위쪽 위치를 지정한 Dialog에 공통 margin을 더하면 여백이 겹쳐 화면 아래로 밀릴 수 있다. 위치와 남은 화면 높이를 함께 정하고, 짧은 화면에서도 닫기와 마지막 내용에 닿는지 확인한다. 닫기·Esc·배경 누르기·뒤로가기와 저장되지 않은 초안 처리를 제품 정책으로 연결한다.

## 확인할 동작

긴 본문만 스크롤되고 제목·닫기·푸터는 보이는지 확인한다. 닫기와 Esc 후 열기 버튼으로 초점이 돌아오는지 검사한다. 푸터 구분선은 선택한 Story에서만 표시한다.
