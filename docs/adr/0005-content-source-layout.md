# 블로그 content가 원본이고, 스킬은 같은 경로로 빌드해 이 저장소에 커밋한다

지침 원본은 `web/apps/blog/content/`이고, 빌드한 스킬은 `references/<영역>/<메뉴>/<문서>/`에 공통 글 `index.md`와 스택 글(`react.md`·`angular.md`·`spring.md`)을 두는 블로그와 같은 3단계 경로를 씁니다. 산출물은 이 저장소의 `.agents/skills/goraebap-webapp/`에 커밋해 이 저장소가 첫 사용자가 되고, 다른 프로젝트는 그 폴더 주소로 설치합니다(저장소 주소만 주면 프로젝트 스킬도 후보로 뜹니다). `SKILL.md`는 영역만 안내하고 영역마다 `README.md`가 문서 목록을 맡습니다.

## 검토한 안

- **메뉴 단계를 뺀 2단계 경로**: 블로그와 경로가 달라 변환기가 메뉴 단계를 지워야 하고 문서 이름이 메뉴 사이에서 겹치면 안 됩니다.
- **별도 저장소나 산출물 전용 브랜치**: 저장소·CI 권한이 늘거나, 브랜치 주소로 받은 스킬을 `npx skills update`가 갱신하는지 확인되지 않았습니다.
