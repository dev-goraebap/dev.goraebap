# 지침은 플러그인이 아니라 스킬 하나로 배포한다

지침을 Webapp 플러그인 대신 스킬 하나 `goraebap-webapp`으로 배포하고, 각 프로젝트는 `npx skills`로 `.agents/skills/`에 받아 커밋합니다. 플러그인은 Claude·Codex·Antigravity용 패키지를 따로 만들어야 했지만, 스킬은 `.agents/skills/`를 읽는 에이전트 모두에 같은 파일로 닿고, 프로젝트마다 쓰는 판이 저장소에 남아 동료끼리 같은 기준을 씁니다. 사용자 범위 플러그인 하나로 모든 프로젝트를 한꺼번에 갱신하던 방식(2026-11-08 "사본 없는 연결")을 이 결정이 대신합니다.

## 검토한 안

- **플러그인 유지**: 갱신은 쉽지만 프로젝트에 판이 남지 않고, 플랫폼별 패키지를 계속 관리해야 합니다.
- **`docs/goraebap-mode/` 문서 + AGENTS.md 라우터**: 리뷰에서는 기준 문서로 읽히지만, AGENTS.md 목록만으로는 Claude Code가 작업 중에 스스로 꺼내 읽지 않았습니다(2026-11-25 프로젝트 스킬 전환 때 관찰).
- **사용자 범위 전역 설치(`-g`)**: 플러그인과 같은 문제(판이 저장소에 없음)가 남습니다.
