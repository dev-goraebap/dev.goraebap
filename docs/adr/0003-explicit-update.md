# 프로젝트의 지침 갱신은 사람이 요청할 때만 한다

프로젝트는 `.agents/skills/goraebap-webapp`과 `skills-lock.json`을 커밋하고, 갱신은 사람이 요청하면 에이전트가 `npx skills update goraebap-webapp -p -y`로 받은 뒤 `metadata.version`과 바뀐 기준을 요약합니다. 새 판이 나왔다는 사실은 블로그의 바뀐 점 목록으로 알립니다. 검토 없이 작업 중에 기준이 바뀌지 않고, 갱신이 PR diff로 보입니다.

## 검토한 안

- **세션 시작 훅이 자동 갱신 또는 알림**: 프로젝트마다 스크립트와 에이전트별 훅이 생기고 세션마다 네트워크를 탑니다. 자동 갱신은 같은 날에도 동료마다 판이 다를 수 있습니다.
- **AGENTS.md에 '시작할 때 확인' 지시**: 지켜진다는 보장이 없고, skills CLI에 새 판 확인만 하는 명령이 없습니다.
