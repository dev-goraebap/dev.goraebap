# goraebap-webapp은 구현 기준만 담고 절차는 외부 하네스에 맡긴다

`goraebap-webapp`에는 레포 구조·프론트엔드·백엔드의 구현 기준만 넣고, 요구사항 정리·명세·티켓·TDD·디버깅·리뷰·ADR 같은 작업 절차는 Pocock 스킬(`mattpocock/skills`) 같은 외부 하네스에 맡깁니다. 의견이 확실한 영역은 구현 기준이고, 절차는 이미 완성도 높은 하네스가 있어 직접 관리할 이유가 약합니다. 기준은 고정하고, 프로젝트가 다르게 하려면 AGENTS.md의 프로젝트 규칙 표에 이유와 함께 적습니다.

하네스와 어떻게 연결할지(리뷰 관문, 온보딩에서 하네스를 다룰지)와 사이트 playbook 공간의 앞날은 아직 정하지 않았습니다.

## 검토한 안

- **Pocock 스킬을 포크해 흡수**: 업스트림 변경이 잦아(1.2.0→1.3.1 사이 PR 번호 #551→#1121) 따라가는 비용이 크고, Pocock도 개인 방식은 포크보다 AGENTS.md에 두라고 합니다.
- **절차 플레이북 유지**: Pocock과 6개가 겹쳐 같은 일을 두 지침이 다르게 말하게 됩니다.
