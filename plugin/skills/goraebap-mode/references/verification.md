# 변경에 맞는 검증

프로젝트의 실제 스크립트와 CI를 확인해 명령을 선택한다. 여기에는 특정 저장소의 경로·포트·검사 명령을 고정하지 않는다.

| 변경 | 확인할 것 |
| --- | --- |
| 화면 | 타입·빌드·프로젝트 검사, 바뀐 주 동작, 해당 화면의 로딩·빈 결과·오류 |
| 반응형·모양 | 데스크톱·휴대폰, 제공하는 밝게·어둡게 모드, 키보드 주 동작 |
| 서버 로직 | 해당 유스케이스·권한·트랜잭션 실패, 프로젝트 정적 검사 |
| API 계약 | 서버 명세와 생성 타입, 영향받는 호출자, 오류 응답 |
| 스키마 | 빈 DB와 이전 버전 사본의 마이그레이션, 데이터 보존·변환 |
| 스킬·문서 | 링크·이름·실제 명령, 동기화, 행동이 달라지는 수정의 대표 상황 |

기존 서버를 임의로 종료하거나 운영 데이터를 검증용으로 바꾸지 않는다. 의미 있는 검증이 통과하면 이유 없이 전체 검사를 반복하지 않는다. 자동 검사 통과와 실제 동작 확인을 구분하고, 하지 않은 검증은 완료로 기록하지 않는다.
