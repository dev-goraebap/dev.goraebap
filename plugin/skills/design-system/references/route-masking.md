# 라우트 마스킹

자기 주소가 있는 작성·수정 양식을 데스크톱 목록 위 대화상자로 엽니다. 목록은 그대로 두고 주소창에는 양식의 실제 주소를 보입니다. 상태·복귀와 직접 링크의 계약은 frontend의 [화면 전환](../../frontend/references/navigation.md)이 소유하고, 키트의 [routed-panel](https://github.com/dev-goraebap/goraebap-workflow/blob/main/kit/reference/patterns/routing/routed-panel.ts)이 구현합니다.

| 진입 | 결과 |
| --- | --- |
| 데스크톱 목록에서 열기 | 목록 주소에 `?panel=대상` + 대상 주소 마스크, 대화상자 |
| 직접 링크·새로고침(`unmaskOnReload`) | 대상 페이지 |
| 휴대폰에서 열기, 휴대폰 폭에서 남은 `?panel` | 대상 페이지 |
| 크게 보기 | 대상 페이지로 바꿔 갑니다(replace). 초안이 남습니다 |
| 닫기·Esc | 이 세션에서 열었으면 히스토리 뒤로(목록의 조건·스크롤 그대로), 아니면 패널만 뺀 목록 |
| 저장 성공 | 결과 페이지로 바꿔 갑니다(replace). 뒤로 가면 목록 |

상세처럼 읽는 대상은 자기 페이지로 열고, 목록을 보며 훑는 것은 [미리보기 패널](peek.md)로 엽니다. 목록 위 대화상자는 작성·수정, 프로필 같은 짧은 보기, 전역 검색에 씁니다. 자기 페이지가 없는 짧은 양식(이름 바꾸기, 폴더 만들기)은 크게 보기 없이 대화상자로만 엽니다.

## 확인할 동작

목록에서 열기 → 초안 입력 → 크게 보기 순서로 조작해 마스크 주소·실제 주소·초안 보존을 확인합니다. 닫기·뒤로·앞으로와 직접 진입, 휴대폰 전체 화면을 확인합니다. 견본은 메모리 히스토리로 같은 훅을 실행합니다. 브라우저 주소·새로고침·링크 공유는 제품의 실제 URL에서 따로 검사하고 기록을 구분합니다.
