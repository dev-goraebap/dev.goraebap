# 간격과 크기

앱의 크기는 rem과 테마 토큰으로 씁니다. 1px 선과 그림자만 px로 둡니다. 그래야 루트 글자 크기를 키울 때 부품 높이·간격·모서리가 함께 커집니다.

## 기본 치수

| 항목 | 데스크톱 | 휴대폰 |
| --- | --- | --- |
| 페이지 머리 줄·사이드바 머리 줄 | 3.25rem | 페이지 머리 줄 최소 3.75rem |
| 툴바 | 2.75rem | 최소 3.75rem |
| 적용한 필터 줄 | 2.5rem | 칩 줄(2.75rem 칩) |
| 컨트롤 sm·md·lg | 1.5·1.75·2rem | 2.75·2.75·3rem |
| 둥근 도구·뷰 알약 | md(1.75rem) | sm(2.75rem) |
| 입력 칸 높이·글자 | 2.25rem·13px | 3rem·16px |
| 동작·선택·시간 목록 행 | 용도별 밀도 | 최소 3rem·본문 15px |
| 텍스트 실행 버튼 최소 너비 | 내용에 맞춤 | 5.5rem |
| 하단 탭 | — | 3.5rem + 홈 표시줄 |
| 페이지 좌우 정렬선 | 1rem | 1rem |
| 읽기·설정·작성 페이지 열 | 최대 45rem | 화면 폭 |
| 상세 속성 열 / 두 열이 되는 컨테이너 폭 | 16rem / 60rem | 한 열 |
| 사이드바 | 열 때 340px, 220~380px | 하단 탭 |

휴대폰은 손가락으로 누르고 화면을 가까이 보지 않습니다. Apple HIG는 누르는 영역을 최소 44pt, 본문 기본을 17pt로 두고, Material 3는 누르는 영역 최소 48dp, FAB 56dp, 본문 14~16sp로 둡니다. 이에 따라 휴대폰에서 누르는 것은 44px 이상을 원칙으로 삼고 컨트롤 sm·md·lg를 2.75·2.75·3rem(44·44·48px)으로, 둥근 도구·뷰 알약을 sm(2.75rem)으로 둡니다. 휴대폰 크기는 키트의 `foundations/responsive.css`, FAB는 `layouts/page/page.module.css`에서 구현합니다.

휴대폰 입력 글자를 16px 아래로 두면 iOS가 입력할 때 화면을 확대합니다. 휴대폰과 데스크톱의 분기점은 하나(`width < 64rem`)입니다. 사이드바↔하단 탭, 팝오버↔바텀시트, 대화상자↔페이지, 표↔행 목록, 알약 크기가 모두 같은 점에서 바뀝니다. 768px처럼 다른 분기점을 섞으면 768~1024px에서 휴대폰 틀에 데스크톱 크기 부품이 놓입니다. 부품 안의 배치는 창 폭 대신 컨테이너 폭(container query)으로 판단해도 됩니다.

## 모바일 조작 영역과 여백

모바일 머리 줄과 툴바는 44px 버튼 위아래에 각각 8px 이상의 여유를 둡니다. 48px 컨트롤을 담으면 줄도 함께 늘립니다. 버튼 높이만 키우고 기존 줄 높이를 유지하지 않습니다. 뒤로가기의 누르는 영역은 44px 이상으로 두고, 안의 화살표는 본문의 왼쪽 정렬선에 맞춥니다. 아이콘 자체의 크기와 누르는 영역은 [아이콘](icons.md) 기준으로 구분합니다.

완료·취소·저장·다음·제출처럼 짧은 이름을 가진 실행 버튼은 모바일에서 최소 88px 너비를 확보합니다. 아이콘 전용 버튼, 뷰·도구·속성 알약에는 이 너비를 적용하지 않습니다. 여러 동작이 한 줄에 들어가지 않으면 줄을 나누거나 보조 동작을 메뉴로 옮깁니다.

## 정렬선

머리 줄·툴바·행의 글자와 아이콘은 같은 1rem 안쪽 선에 맞춥니다. 본문 열 자체에는 좌우 여백을 두지 않고 행이 자기 안쪽 여백을 가집니다. 그래야 행의 hover 바탕과 구분선이 작업 영역 끝까지 닿습니다. 메뉴·대화상자 안의 행은 자기 여백(8px)을 씁니다.

같은 역할의 도구(검색·필터·표시)는 같은 좁은 간격으로 묶고, 만들기 버튼은 그보다 넓은 간격 뒤에 둡니다. 사이 간격으로 역할의 경계를 보입니다.

## 큰 화면과 확대

1920px부터 너비에 따라 루트 글자를 키워 2560px에서 19px(118.75%)에 이릅니다. 27인치 QHD에서 24인치 FHD의 16px과 같은 실제 크기가 됩니다. 브라우저 확대도 rem을 따라 함께 커져야 합니다. Astryx가 px로 고정한 크기(버튼 안 16px 아이콘 칸, 12px 꺾쇠)는 props로 끝내지 말고 생성 CSS를 확인합니다. 큰 화면 배율은 사용 환경을 보고 프로젝트가 정합니다.

목록 밀도(행 높이)는 앱 설정 한 곳에서 정하고 모든 페이지 목록·표가 따릅니다. 메뉴·대화상자 안의 목록은 자기 용도의 크기를 유지합니다.
