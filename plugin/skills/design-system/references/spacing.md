# 간격과 크기

앱의 크기는 rem과 테마 토큰으로 쓴다. 1px 선과 그림자만 px로 둔다. 그래야 루트 글자 크기를 키울 때 부품 높이·간격·모서리가 함께 커진다.

## 기본 치수

| 항목 | 데스크톱 | 휴대폰 |
| --- | --- | --- |
| 페이지 머리 줄·사이드바 머리 줄 | 3.25rem | 3.25rem |
| 툴바 | 2.75rem | 3.25rem |
| 적용한 필터 줄 | 2.5rem | 칩 줄(2rem 칩) |
| 컨트롤 sm·md·lg | 1.5·1.75·2rem | 2·2.5·2.75rem |
| 둥근 도구·뷰 알약 | md(1.75rem) | sm(2rem) |
| 입력 칸 높이·글자 | 2.25rem·13px | 3rem·16px |
| 하단 탭 | — | 3.5rem + 홈 표시줄 |
| 페이지 좌우 정렬선 | 1rem | 1rem |
| 읽기·설정·작성 페이지 열 | 최대 45rem | 화면 폭 |
| 상세 속성 열 / 두 열이 되는 컨테이너 폭 | 16rem / 60rem | 한 열 |
| 사이드바 | 열 때 340px, 220~380px | 하단 탭 |

휴대폰 입력 글자를 16px 아래로 두면 iOS가 입력할 때 화면을 확대한다. 휴대폰과 데스크톱의 분기점은 하나(`width < 64rem`)다. 사이드바↔하단 탭, 팝오버↔바텀시트, 대화상자↔페이지, 표↔행 목록, 알약 크기가 모두 같은 점에서 바뀐다. 768px처럼 다른 분기점을 섞으면 768~1024px에서 휴대폰 틀에 데스크톱 크기 부품이 놓인다. 부품 안의 배치는 창 폭 대신 컨테이너 폭(container query)으로 판단해도 된다.

## 정렬선

머리 줄·툴바·행의 글자와 아이콘은 같은 1rem 안쪽 선에 맞춘다. 본문 열 자체에는 좌우 여백을 두지 않고 행이 자기 안쪽 여백을 가진다. 그래야 행의 hover 바탕과 구분선이 작업 영역 끝까지 닿는다. 메뉴·대화상자 안의 행은 자기 여백(8px)을 쓴다.

같은 역할의 도구(검색·필터·표시)는 같은 좁은 간격으로 묶고, 만들기 버튼은 그보다 넓은 간격 뒤에 둔다. 사이 간격으로 역할의 경계를 보인다.

## 큰 화면과 확대

1920px부터 너비에 따라 루트 글자를 키워 2560px에서 19px(118.75%)에 이른다. 27인치 QHD에서 24인치 FHD의 16px과 같은 실제 크기가 된다. 브라우저 확대도 rem을 따라 함께 커져야 한다. Astryx가 px로 고정한 크기(버튼 안 16px 아이콘 칸, 12px 꺾쇠)는 props로 끝내지 말고 생성 CSS를 확인한다. 큰 화면 배율은 사용 환경을 보고 프로젝트가 정한다.

목록 밀도(행 높이)는 앱 설정 한 곳에서 정하고 모든 페이지 목록·표가 따른다. 메뉴·대화상자 안의 목록은 자기 용도의 크기를 유지한다.
