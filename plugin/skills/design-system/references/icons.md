# 아이콘

아이콘은 명령·상태·대상을 구분하는 시각 언어입니다. 화면은 의미 이름(`search`, `back`, `layout-list`)으로 아이콘을 부르고, 의미 이름에서 Solar 아이콘으로 가는 매핑은 [생성 스크립트](https://github.com/dev-goraebap/goraebap-workflow/blob/main/kit/scripts/generate-icons.mjs) 한 곳에 둡니다. 사용하는 이름만 생성하며, 이름을 더하면 스크립트를 다시 실행합니다.

## 기본과 선택

기본은 Linear, 고름·열림·눌림·현재 위치는 같은 아이콘의 Bold Duotone입니다(`solarIcon(name, isChosen)`). 사이드바의 현재 항목, 하단 탭, 켜진 도구, 열린 메뉴(…), 고른 뷰가 모두 같은 규칙을 따릅니다. 기본·선택 비교는 같은 의미 이름으로 확인합니다.

## 크기와 정렬

13px 본문 옆 아이콘은 16px(약 1.2배)에서 출발합니다. 하단 탭은 24px, 알약 안은 14px입니다. 16px 루트에서는 글자 옆 아이콘의 잉크가 약 0.5px 낮게 보여 반 픽셀 올리고, 루트가 커지는 1920px 이상에서는 보정을 멈춥니다. 부품마다 별도의 이동값을 누적하지 않습니다.

## 고르는 기준

| 상황 | 아이콘 |
| --- | --- |
| 화면에서 나가는 뒤로(머리 줄·시트·필터 단계) | `back`(왼쪽 화살표 ←) |
| 날짜·단계의 이전·다음, 경로 구분 | `previous`·`forward`(꺾쇠) |
| 닫기·지우기 | `close` |
| 더 많은 동작 | `more`(…) |
| 만들기 | `plus` |
| 권한·보호 | `shield` |

장식 아이콘은 접근성 트리에서 숨깁니다. 아이콘만 있는 버튼에는 이름(`label`)과 툴팁을 줍니다. 아이콘만으로 뜻을 알아보기 어려우면 이름을 함께 보입니다. 상태 차이를 색만으로 표현하지 않습니다.
