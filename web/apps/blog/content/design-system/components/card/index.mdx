## 구성

| 부분 | 역할 |
| --- | --- |
| Card | 경계선, 배경, 여백과 클릭 가능 상태를 담당하는 카드 외곽 컨테이너입니다. |
| CardHeader | 제목과 보조 설명을 상단에 묶어 배치하는 영역입니다. |
| CardTitle | 카드가 다루는 대상이나 주제를 알리는 제목입니다. |
| CardDescription | 제목 아래에 맥락을 짧게 보충하는 설명입니다. |
| CardContent | 본문 텍스트, 폼, 지표 등 핵심 내용을 담는 영역입니다. |
| CardFooter | 카드 하단에 보조 정보나 실행 버튼을 배치하는 영역입니다. |

## 접근성

- 카드 전체를 클릭 대상으로 만들 때는 내부에 버튼이나 다른 링크가 중첩되지 않게 구성합니다.
- 페이지의 제목 위계에 맞춰 CardTitle의 시맨틱 수준을 일관되게 유지합니다.
