파일 목록, 캔버스, 표 행처럼 특정 대상 위에서 마우스 우클릭으로 관련 동작 목록을 열 때 씁니다. 화면에 버튼을 노출하지 않고도 대상별 빠른 편집 동작을 제공합니다.

## 구성

| 부분 | 역할 |
| --- | --- |
| ContextMenu | 우클릭 메뉴의 열림 상태와 포인터 좌표를 관리하는 최상위 래퍼입니다. |
| ContextMenuTrigger | 우클릭 이벤트를 받아 메뉴를 여는 대상 영역입니다. |
| ContextMenuContent | 포인터 위치에 맞춰 띄워지는 메뉴 패널입니다. |
| ContextMenuItem | 클릭이나 Enter로 동작을 실행하는 개별 항목입니다. |
| ContextMenuSeparator | 동작 묶음이나 위험 동작을 구분하는 선입니다. |

## 접근성

| 키 | 동작 |
| --- | --- |
| ArrowUp / ArrowDown | 메뉴 안의 이전·다음 항목으로 이동합니다. |
| Enter | 강조된 항목을 실행합니다. |
| Esc | 메뉴를 닫습니다. |

- 터치 기기에는 우클릭이 없으므로 중요한 동작은 [Menu](../menu/index.mdx) 버튼이나 [Bottom Sheet](../bottom-sheet/index.mdx)로도 함께 제공합니다.
- 삭제 같은 위험 동작은 ContextMenuSeparator 아래에 두고 <Term id="destructive">Destructive</Term> 스타일로 구분합니다.

## 적응형 UI

터치 환경에는 우클릭이 없으므로 더보기 버튼과 useIsMobile 분기 BottomSheet로 같은 동작을 제공합니다. 자세한 기준은 [적응형 UI](../../adaptive-ui/index.mdx)에 있습니다.

## 관련 컴포넌트

- [Menu](../menu/index.mdx): 우클릭 대신 눈에 보이는 더보기 버튼으로 동작 목록을 열 때 씁니다.
- [Popover](../popover/index.mdx): 동작 목록이 아니라 설정 폼이나 보조 정보를 띄울 때 씁니다.
