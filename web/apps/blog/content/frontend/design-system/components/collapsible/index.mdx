고급 필터나 부가 설명처럼 단일 영역 하나를 필요할 때만 펼쳐 보여 줄 때 씁니다. 아코디언처럼 여러 항목을 묶지 않고 독립된 구획 하나를 여닫을 때 적합합니다.

## 구성

| 부분 | 역할 |
| --- | --- |
| Collapsible | 단일 영역의 열림 상태를 관리하는 최상위 래퍼입니다. |
| CollapsibleTrigger | 클릭이나 키보드로 영역을 접고 펼치는 트리거 버튼입니다. |
| CollapsibleContent | 열림 상태에 따라 표시되는 본문 영역입니다. |

## 접근성

| 키 | 동작 |
| --- | --- |
| Tab | 트리거 버튼으로 포커스를 이동합니다. |
| Enter | 영역을 펼치거나 접습니다. |
| Space | 영역을 펼치거나 접습니다. |

- 트리거 라벨에 '고급 옵션 보기'처럼 펼쳤을 때 무엇이 나오는지 드러냅니다.
- 핵심 입력이나 필수 안내는 접힌 영역 안에 숨기지 않습니다.
