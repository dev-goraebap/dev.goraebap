화면 왼쪽이나 오른쪽 가장자리에서 슬라이드되어 나오는 드로어 패널입니다. 메인 본문의 맥락을 유지한 채 탐색 메뉴, 상세 필터, 속성 편집 패널을 열 때 씁니다.

## 구성

| 부분 | 역할 |
| --- | --- |
| Drawer | 드로어의 열림 상태와 오버레이 컨텍스트를 관리하는 최상위 래퍼입니다. |
| DrawerTrigger | 클릭이나 키보드로 드로어를 여는 트리거 요소입니다. |
| DrawerContent | 배경 막과 측면 패널 본체를 렌더링하며 기본 닫기 버튼을 포함합니다. |
| DrawerTitle | 드로어의 목적을 알리는 제목이며 스크린 리더에 연결됩니다. |
| DrawerDescription | 패널의 역할을 짧게 보충하는 설명입니다. |
| DrawerClose | 내부 버튼으로 드로어를 닫을 때 감싸는 요소입니다. |

## 접근성

| 키 | 동작 |
| --- | --- |
| Tab | 드로어 안의 다음 조작 요소로 포커스를 이동합니다. |
| Shift+Tab | 드로어 안의 이전 조작 요소로 포커스를 이동합니다. |
| Esc | 드로어를 닫고 열었던 트리거로 포커스를 되돌립니다. |

- DrawerTitle을 반드시 포함해 스크린 리더가 패널 이름을 읽을 수 있게 합니다.
- 닫기 버튼을 showCloseButton=&#123;false&#125;로 숨긴 경우에도 DrawerClose로 닫는 경로를 제공합니다.
