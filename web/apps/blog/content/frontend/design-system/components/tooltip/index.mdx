아이콘 버튼의 이름이나 짧은 단축키처럼 화면을 어지럽히지 않고 보조 설명만 덧붙일 때 씁니다. 호버나 포커스 시 잠시 나타나는 비모달 말풍선입니다.

## 구성

| 부분 | 역할 |
| --- | --- |
| TooltipProvider | 여러 툴팁의 열림 지연과 전환 타이밍을 공유하는 상위 프로바이더입니다. |
| Tooltip | 개별 툴팁의 열림 상태를 관리하는 래퍼입니다. |
| TooltipTrigger | 호버나 포커스를 받아 툴팁을 띄우는 대상 요소입니다. |
| TooltipContent | 짧은 안내 문구를 표시하는 말풍선 본체입니다. |

## 접근성

| 키 | 동작 |
| --- | --- |
| Tab | 트리거 요소에 포커스를 옮겨 툴팁을 엽니다. |
| Esc | 열려 있는 툴팁을 즉시 닫습니다. |

- 터치 기기에는 호버가 없으므로 필수 정보나 오류 안내를 Tooltip 안에만 두지 않습니다.
- 툴팁 안에는 버튼이나 링크 같은 상호작용 요소를 넣지 않습니다.
