사용자 이름이나 문서 링크에 마우스를 올렸을 때 페이지를 이동하지 않고 요약 정보를 미리 보여 주는 비모달 카드입니다. 본문 흐름을 끊지 않고 대상의 맥락을 확인할 때 씁니다.

## 구성

| 부분 | 역할 |
| --- | --- |
| PreviewCard | 미리보기 카드의 열림 지연과 상태를 관리하는 최상위 래퍼입니다. |
| PreviewCardTrigger | 호버나 포커스를 받아 카드를 여는 링크·트리거 요소입니다. |
| PreviewCardContent | 요약 프로필이나 문서 미리보기를 담는 팝업 카드입니다. |

## 접근성

| 키 | 동작 |
| --- | --- |
| Tab | 트리거에 포커스를 옮겨 미리보기 카드를 엽니다. |
| Esc | 열려 있는 미리보기 카드를 닫습니다. |

- 터치 환경에는 호버가 없으므로 핵심 동작이나 필수 정보는 카드 안에만 두지 않고 링크 대상 페이지에서 제공합니다.
- 트리거는 클릭 시 원래 대상 페이지로 이동하는 정상적인 링크로 유지합니다.

## 관련 컴포넌트

- [Tooltip](../tooltip/index.mdx): 요약 카드가 아니라 한 줄짜리 짧은 설명만 띄울 때 씁니다.
- [Popover](../popover/index.mdx): 호버가 아니라 클릭으로 열고 닫으며 내부에서 조작해야 할 때 씁니다.
