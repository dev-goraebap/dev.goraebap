글꼴 굵게, 즐겨찾기, 음소거처럼 버튼 하나를 눌러 켜짐과 꺼짐 상태를 유지할 때 씁니다. 툴바나 편집 도구 안에서 현재 적용된 상태를 바로 보여 줄 때 적합합니다.

## 접근성

| 키 | 동작 |
| --- | --- |
| Tab | 토글 버튼으로 포커스를 이동합니다. |
| Enter | 눌림 상태를 전환합니다. |
| Space | 눌림 상태를 전환합니다. |

- 아이콘만 표시하는 토글에는 aria-label로 접근 가능한 이름을 반드시 적습니다.
- 눌린 상태가 바뀌어도 버튼 라벨 자체를 바꾸지 말고 눌림 상태로만 표현합니다.

## 관련 컴포넌트

- [Button](../button/index.mdx): 상태를 유지하지 않고 한 번 실행하고 끝나는 동작은 Button을 씁니다.
- [Toggle Group](../toggle-group/index.mdx): 서로 관련된 토글 여러 개를 묶어 단일·다중 선택으로 관리할 때 씁니다.
- [Switch](../switch/index.mdx): 설정 화면에서 기능 켜짐·꺼짐을 명확히 구분할 때 씁니다.
