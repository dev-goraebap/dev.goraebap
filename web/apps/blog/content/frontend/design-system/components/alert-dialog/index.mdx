삭제, 탈퇴, 초기화처럼 되돌릴 수 없는 작업을 실행하기 전에 사용자의 명시적인 확인을 받는 모달입니다. 바깥 클릭으로 실수로 닫히지 않고 내부 버튼으로만 결정을 끝냅니다.

## 구성

| 부분 | 역할 |
| --- | --- |
| AlertDialog | 확인창의 열림 상태와 포커스 트랩을 관리하는 최상위 래퍼입니다. |
| AlertDialogTrigger | 확인창을 여는 트리거 요소입니다. |
| AlertDialogContent | <Term id="backdrop">배경 막</Term>과 중앙 확인창 본체를 렌더링합니다. |
| AlertDialogTitle | 확인할 위험 동작을 분명히 알리는 제목입니다. |
| AlertDialogDescription | 실행 시 잃게 되는 데이터나 영향을 설명하는 본문입니다. |
| AlertDialogFooter | 취소와 실행 버튼을 배치하는 하단 영역입니다. |
| AlertDialogClose | 취소나 확인 뒤 창을 닫는 버튼 래퍼입니다. |

## 접근성

| 키 | 동작 |
| --- | --- |
| Tab | 확인창 안의 다음 버튼으로 포커스를 이동합니다. |
| Shift+Tab | 확인창 안의 이전 버튼으로 포커스를 이동합니다. |
| Esc | 작업을 실행하지 않고 확인창을 닫습니다. |

- AlertDialogTitle과 AlertDialogDescription을 모두 채워 스크린 리더가 위험 내용을 바로 읽게 합니다.
- 실행 버튼에는 '확인' 대신 '프로젝트 삭제'처럼 대상을 포함한 구체적 동사를 씁니다.

## 적응형 UI

파괴적 확인은 바텀시트로 전환하지 않고 모바일에서도 중앙 모달을 그대로 유지합니다. 자세한 기준은 [적응형 UI](../../../interaction/adaptive-ui/index.mdx)에 있습니다.
