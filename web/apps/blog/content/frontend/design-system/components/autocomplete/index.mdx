## 구성

| 부분 | 역할 |
| --- | --- |
| Autocomplete | 입력값과 추천 목록 열림 상태를 관리하는 최상위 래퍼입니다. |
| AutocompleteInput | 사용자가 자유 텍스트를 입력하는 입력 칸입니다. |
| AutocompleteContent | 추천 후보를 띄우는 팝업 컨테이너입니다. |
| AutocompleteList | 추천 항목들을 나열하는 목록 영역입니다. |
| AutocompleteItem | 선택 시 입력 칸에 채워지는 개별 추천 항목입니다. |
| AutocompleteEmpty | 일치하는 추천이 없을 때 표시하는 안내 영역입니다. |

## 접근성

| 키 | 동작 |
| --- | --- |
| ArrowUp / ArrowDown | 추천 목록에서 이전·다음 항목을 강조합니다. |
| Enter | 강조된 추천 항목을 입력 칸에 채웁니다. |
| Esc | 추천 목록 팝업을 닫습니다. |

- AutocompleteInput에 label이나 aria-label로 접근 가능한 이름을 제공합니다.
- 모바일에서는 가상 키보드가 화면을 가리지 않도록 추천 개수를 적절히 제한합니다.

## 적응형 UI

좁은 화면에서는 useIsMobile로 분기해 BottomSheet나 독립 스크롤 목록으로 추천 항목을 보여 줍니다. 자세한 기준은 [적응형 UI](../../../interaction/adaptive-ui/index.mdx)에 있습니다.
