## 접근성

- 페이지 전체 본문은 모바일 관성 스크롤을 살리기 위해 네이티브 스크롤을 우선 쓰고, 부분 패널에만 ScrollArea를 적용합니다.
- 키보드 사용자가 스크롤 영역에 접근할 수 있도록 내부 콘텐츠의 포커스 흐름을 막지 않습니다.

## 관련 컴포넌트

- [Table](../table/index.mdx): 구조화된 행·열 데이터의 가로 스크롤은 Table을 씁니다.
- [Drawer](../drawer/index.mdx): 긴 탐색이나 필터 목록을 별도 측면 패널로 열 때 씁니다.
