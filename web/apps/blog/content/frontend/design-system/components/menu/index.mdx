## 구성

| 부분 | 역할 |
| --- | --- |
| Menu | 메뉴의 열림 상태와 항목 탐색을 관리하는 최상위 래퍼입니다. |
| MenuTrigger | 클릭이나 키보드로 메뉴를 여는 트리거 버튼입니다. |
| MenuContent | 동작 항목들을 담아 띄우는 팝업 패널입니다. |
| MenuGroup | 성격이 같은 메뉴 항목들을 묶는 그룹입니다. |
| MenuLabel | 메뉴 그룹의 성격을 알리는 비클릭 제목입니다. |
| MenuItem | 클릭이나 Enter로 동작을 실행하는 개별 항목입니다. |
| MenuSeparator | 일반 동작과 위험 동작 같은 구역을 나누는 구분선입니다. |

## 접근성

| 키 | 동작 |
| --- | --- |
| Enter / Space | 메뉴를 열거나 강조된 항목을 실행합니다. |
| ArrowUp / ArrowDown | 메뉴 안의 이전·다음 항목으로 이동합니다. |
| Esc | 메뉴를 닫고 트리거로 포커스를 되돌립니다. |

- 삭제처럼 되돌리기 어려운 항목은 MenuSeparator 아래에 두고 <Term id="destructive">Destructive</Term> 스타일로 구분합니다.
- 아이콘만 있는 더보기 트리거에는 aria-label로 접근 가능한 이름을 적습니다.

## 적응형 UI

자동 전환 래퍼가 없으므로 64rem 미만에서는 useIsMobile로 분기해 BottomSheet에 44px 이상 항목을 배치합니다. 자세한 기준은 [적응형 UI](../../../interaction/adaptive-ui/index.mdx)에 있습니다.
