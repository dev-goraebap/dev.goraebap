저장, 제출, 삭제처럼 누르는 즉시 실행되는 동작에 씁니다. 한 화면에는 <Term id="primary">Primary</Term> 액션을 하나만 두어 시각적 위계를 세우고, 나머지는 <Term id="secondary">Secondary</Term>나 <Term id="ghost">Ghost</Term>로 낮추며, 되돌리기 어려운 파괴적 동작은 <Term id="destructive">Destructive</Term> 스타일로 구분합니다.

## 구성

<Demo>
<ComponentAnatomyFigure slug="button" />
</Demo>

| 부분 | 역할 |
| --- | --- |
| Container | 배경, 테두리, 반경과 호버·포커스·<Term id="disabled">비활성</Term> 상태를 담당하는 버튼 영역입니다. |
| Icon | 동작의 의미를 빠르게 전달하며, 아이콘만 둘 때는 size="icon"과 aria-label을 함께 씁니다. |
| Label | 버튼을 눌렀을 때 일어나는 동작을 한두 단어로 짧게 적습니다. |

## 접근성

| 키 | 동작 |
| --- | --- |
| Tab | 버튼으로 포커스를 이동합니다. |
| Enter | 포커스된 버튼을 실행합니다. |
| Space | 포커스된 버튼을 실행합니다. |

- 아이콘만 넣은 버튼(size="icon")에는 aria-label로 동작 이름을 반드시 적습니다.
- 폼 안에서 제출이 아닌 버튼에는 type="button"을 명시합니다. 링크로 합성할 때 넘길 값은 스택 글에 있습니다.
