자주 묻는 질문이나 여러 설정 구획을 제목만 보여 주고 필요할 때 펼쳐 읽게 할 때 씁니다. 긴 페이지를 구조화해 한 화면의 정보 부담을 줄이는 데 적합합니다.

## 구성

| 부분 | 역할 |
| --- | --- |
| Accordion | 단일·다중 열림 규칙과 항목 간 탐색을 관리하는 최상위 컨테이너입니다. |
| AccordionItem | 하나의 제목과 본문 쌍을 묶는 항목 단위입니다. |
| AccordionTrigger | 클릭이나 키보드로 해당 항목을 접고 펼치는 헤더 버튼입니다. |
| AccordionContent | 펼쳤을 때 드러나는 본문 패널입니다. |

## 접근성

| 키 | 동작 |
| --- | --- |
| Tab | 아코디언 트리거와 열린 본문 요소 사이로 포커스를 이동합니다. |
| Enter / Space | 현재 항목을 펼치거나 접습니다. |

- 트리거 제목은 펼치기 전에 내용을 짐작할 수 있게 간결하고 명확하게 적습니다.
- 필수 입력 항목이나 오류 메시지가 있는 구역은 접어 두지 않습니다.

## 관련 컴포넌트

- [Collapsible](../collapsible/index.mdx): 여러 항목 묶음이 아니라 단일 영역 하나만 접고 펼칠 때 씁니다.
- [Tabs](../tabs/index.mdx): 세로로 쌓지 않고 같은 자리에서 여러 보기 중 하나를 전환할 때 씁니다.
