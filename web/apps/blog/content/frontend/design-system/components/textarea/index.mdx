## 접근성

| 키 | 동작 |
| --- | --- |
| Tab | 다음 입력 칸이나 조작 요소로 포커스를 이동합니다. |
| Shift+Tab | 이전 입력 칸이나 조작 요소로 포커스를 이동합니다. |
| Enter | 입력 중인 내용에 줄바꿈을 추가합니다. |

- label 요소를 연결하거나 aria-label로 접근 가능한 이름을 반드시 제공합니다.
- 유효성 검사 오류는 테두리 변화만으로 알리지 말고 원인 문구를 함께 표시합니다.
- 글자 수 제한이 있으면 현재 입력 길이와 최대 길이를 필드 주변에 함께 알립니다.

- [Alert](../alert/index.mdx): 폼 전체의 제출 오류나 안내 메시지를 묶어 보여 줄 때 씁니다.
