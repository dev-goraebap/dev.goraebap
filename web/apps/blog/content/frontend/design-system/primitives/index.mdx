버튼·라벨·아바타·입력처럼 독립된 UI 역할을 가진 컴포넌트는 [레지스트리로 받은](../packages.mdx) 디자인 시스템의 기본 컴포넌트를 그대로 씁니다. 이름만 바꾼 래퍼를 만들어 API를 복제하지 않습니다. 고래밥의 기준은 변형·크기와 쓰임 구분이며, 컴포넌트 API(조합, 폼 칸 묶기, 요소 바꾸기 등)는 컴포넌트 라이브러리의 공식 문서를 따릅니다. 링크처럼 다른 요소로 그려야 할 때는 감싸는 래퍼를 새로 만들지 않고 라이브러리가 정한 요소 바꾸기 방식을 씁니다.

| 컴포넌트 | 쓰는 곳 | 기준 |
| --- | --- | --- |
| 버튼 | 실행 동작 | 크기·종류와 관계없이 칩(완전히 둥근 모양)입니다. 일반 제출·확인은 기본 칩, 취소는 테두리 없는 버튼, 되돌리기 어려운 동작은 위험 변형. 페이지의 만들기만 만들기 변형, 툴바의 둥근 도구는 도구 변형과 켜진 도구 변형, 뷰 칩은 보기 변형과 고른 보기 변형 |
| 아이콘 버튼 | 아이콘만 있는 동작 | 이름과 툴팁을 둡니다. 열린 메뉴·켜진 상태는 아이콘의 선택 형태 |
| 라벨 | 분류·라벨 | 둥근 칩. 링크가 될 수 있습니다. 실행 도구를 라벨처럼 꾸미지 않습니다 |
| 개수 표시 | 개수 | 개수에만 씁니다. 상태는 라벨로 보입니다 |
| 도구 점 | 조건 있음 | 도구 모서리의 점. 이름을 함께 둡니다. 상태 점 컴포넌트는 따로 두지 않습니다 |
| 아바타 | 사람 | 원형. 사람은 사진과 이름을 함께 보이고, 지정 안 됨도 같은 자리와 폭을 지킵니다 |
| 입력·여러 줄 입력·셀렉트 | 이름 있는 값 | 데스크톱 36px·13px, 휴대폰 48px·16px. 입력 칸이라 모서리는 10px입니다. 폼 배치는 라이브러리의 칸 묶음 컴포넌트로 합니다. 큰 목록은 셀렉트 대신 검색이 있는 고르기를 씁니다 |
| 셀렉트 팝업 | 고르기의 선택지 | 여는 버튼의 폭에 묶이지 않고 가장 긴 항목의 폭을 따릅니다(최소는 버튼 폭과 9rem 중 큰 쪽). 항목은 최소 36px이며 잘려 보이지 않습니다 |
| 대화상자 기본 컴포넌트 | 열기·닫기·초점 경계 | 제품 화면은 [대화상자](../dialog.mdx)를 씁니다. 기본 컴포넌트를 직접 쓰지 않습니다 |

## 조작 면

secondary 버튼, 도구, 보기 탭, 속성 칩, 셀렉트, 필터는 같은 조작 면 토큰 네 개(기본 채움·포인터 아래·고른 것·테두리)를 씁니다. 값은 라이트·다크 모두 글자색을 면 색에 섞어 만듭니다. 화면마다 채움의 진하기를 따로 정하지 않습니다.

| 토큰의 역할 | 쓰임 | 값 |
| --- | --- | --- |
| 기본 채움 | 조작 면의 바탕 | 글자 5% |
| 포인터 아래 | 포인터가 올라온 조작 면 | 글자 9% |
| 고른 것·켜진 것 | 고른 값, 켜진 도구 | 글자 14% |
| 테두리 | 조작 면의 테두리 | 글자 11% |

버튼은 칩이고 초타원(squircle)을 쓰지 않습니다. 묶음 안 버튼의 모양(크기·변형)은 자손 선택자로 덮어쓰지 않고 묶음이 내려 주는 설정(컨텍스트)으로 정합니다. 포털로 뜨는 메뉴·팝오버 안에서는 이 설정을 끊습니다. 끊지 않으면 툴바의 작은 버튼 설정이 그 툴바에서 연 메뉴의 버튼까지 줄입니다.

역할·권한(보기·편집·관리)은 글자만이 아니라 아이콘과 함께 보입니다. 같은 이름의 역할이 화면마다 같은 아이콘을 씁니다.

제목·본문을 쓰는 양식의 입력은 이 표가 아니라 [생성 양식](../creation-form.mdx)을 따릅니다. 날짜는 키트의 공통 달력·날짜 고르기 하나를 쓰고(브라우저 기본 날짜 선택기를 섞지 않습니다), 시간은 직접 입력과 목록을 함께 제공하는 공통 입력으로 받습니다.

모바일 실행 버튼의 최소 너비와 줄 여백은 [간격과 크기](../spacing.mdx)를 따릅니다. 프로필 그림은 28~32px로 두고 누르는 영역을 별도로 최소 44px 확보합니다. 입력의 날짜 열기 버튼, 분할 선택 버튼의 각 항목, 순서 변경 손잡이도 누르는 영역을 확인합니다. 컨트롤 바깥 상자만 커지고 실제 선택 항목은 작게 남지 않게 합니다.
