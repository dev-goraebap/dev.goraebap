화면에 컴포넌트를 쓰거나 고칠 때 이 목록에서 해당 컴포넌트 문서 하나만 엽니다. 각 문서는 쓰임, 구성, 변형, 접근성, 관련 컴포넌트를 다루고 구현 코드는 스택 글에 있습니다.

## 동작과 입력

| 컴포넌트 | 쓰임 |
| --- | --- |
| [Button](components/button/index.mdx) | 동작을 실행하거나 링크로 이동하는 버튼 |
| [Input](components/input/index.mdx) | 한 줄 텍스트 입력과 invalid 오류 상태를 함께 표현하는 입력 칸 |
| [Textarea](components/textarea/index.mdx) | 여러 줄 설명이나 메모를 작성하는 입력 칸 |
| [Switch](components/switch/index.mdx) | 즉시 반영되는 켜짐·꺼짐 설정용 토글 스위치 |
| [Checkbox](components/checkbox/index.mdx) | 여러 항목 선택이나 동의 여부 확인용 체크박스 |
| [Toggle](components/toggle/index.mdx) | 켜짐과 꺼짐 두 상태를 전환하는 토글 버튼 |
| [Toggle Group](components/toggle-group/index.mdx) | 여러 옵션 중 하나 또는 복수를 고르는 세그먼트 토글 그룹 |
| [Select](components/select/index.mdx) | 미리 정해진 목록에서 하나의 값을 고르는 선택 컨트롤 |
| [Radio Group](components/radio-group/index.mdx) | 서로 배타적인 여러 선택지 중 하나를 고르는 라디오 그룹 |
| [Slider](components/slider/index.mdx) | 정해진 범위 안에서 연속된 값을 드래그로 조절하는 슬라이더 |
| [Combobox](components/combobox/index.mdx) | 텍스트 입력으로 후보 목록을 필터링해 값을 고르는 콤보박스 |
| [Autocomplete](components/autocomplete/index.mdx) | 자유 입력을 허용하면서 추천 검색어나 후보를 제안하는 자동완성 입력 칸 |
| [OTP Field](components/otp-field/index.mdx) | 이메일·문자 인증번호처럼 고정 길이 코드를 한 자리씩 입력하는 칸 |

| [Collapsible](components/collapsible/index.mdx) | 단일 보조 영역을 필요할 때만 펼치거나 접는 컨테이너 |
| [Avatar](components/avatar/index.mdx) | 프로필 이미지와 로드 실패 시 이니셜 대체 표시를 묶은 아바타 |
| [Progress](components/progress/index.mdx) | 작업 완료율이나 업로드 진행 상태를 보여 주는 막대 |
| [Scroll Area](components/scroll-area/index.mdx) | 고정 높이 영역 안에서 일관된 커스텀 스크롤바를 제공하는 스크롤 컨테이너 |
