## 상태를 나누는 기준

빈 목록, 검색 결과 없음, 404, 서버 오류를 한 가지 안내 문구로 묶어 두면 사용자는 기다려야 하는지, 조건을 바꿔야 하는지, 다시 시도해야 하는지 판단하기 어렵습니다. 원인과 다음 행동이 다르므로 상태를 분명히 구분합니다.

목록·상세는 다음 순서로 판단합니다.

1. 첫 대기에는 이름 있는 진행 표시를 내용 자리 가운데에 둡니다. 빈 화면이나 이름 없는 표시로 두지 않습니다.
2. 보일 내용 없이 실패하면 실패 그림과 무엇을 못 했는지를 보이고, 다시 시도를 둡니다.
3. 없는 대상(404)은 찾을 수 없음 그림과 돌아갈 곳을 보입니다.
4. 조건이 있는 0건은 결과 없음 그림, 제목("조건에 맞는 …이 없습니다"), "조건 지우기" 버튼을 둡니다.
5. 조건 없는 0건은 빈 그림, 제목, "새로 만들기" 버튼을 둡니다. 머리의 만들기 버튼은 그대로 둡니다.

이미 보이는 내용이 있는 재조회 실패에는 전체 상태 화면을 덮지 않습니다. 내용을 남기고 배너나 그 구역의 한 줄로 알립니다. 일부 출처만 실패하면 실패한 것을 빼고 보여 준다고 알립니다.

## 상태 화면

상태 화면은 펜 선 그림, 제목, 필요할 때의 설명, 행동으로 이뤄집니다. 빈 화면과 검색 결과 없음은 제목과 버튼만 둡니다. 설명은 오류의 원인처럼 제목이 말하지 못하는 사실이 있을 때만 씁니다. 사용법 안내("등록하면 여기에 보입니다", "조건을 바꿔 보세요", "다른 단어로 찾아보세요")는 쓰지 않고, 할 수 있는 행동은 버튼으로 둡니다([문구·본문과 검증](../../../design-system/content-and-review.mdx)).

그림은 테마 색으로 칠해 라이트·다크에서 같은 파일을 씁니다. 페이지에서는 문구를 창 높이의 32%에 고정해 필터 줄·탭이 다른 페이지 사이를 오가도 흔들리지 않습니다. 대화상자·패널·작은 구역은 위쪽에 두는 작은 형태를 씁니다. 그림은 장식이라 접근성 트리에서 숨깁니다.

## 이미지와 글의 등장

상태 화면이 아무 예고 없이 툭 나타나면 화면이 끊긴 것처럼 느껴지고, 그림이 늦게 도착하면 아래 글이 밀리며 배치가 흔들립니다.

상태 그림은 자리를 먼저 잡아 두고 도착하면 600ms에 걸쳐 한 번만 드러내며, 이미 본 그림은 다시 흐리게 시작하지 않습니다. 글은 420ms 동안 짧게 떠오르게 합니다. 움직임 줄이기 설정이 켜져 있으면 애니메이션 없이 바로 표시합니다.

```css
@keyframes page-state-enter {
  from {
    opacity: 0;
    transform: translateY(0.375rem);
  }
  to {
    opacity: 1;
    transform: none;
  }
}

.page-state {
  animation: page-state-enter 420ms cubic-bezier(0.2, 0, 0, 1) both;
}

@media (prefers-reduced-motion: reduce) {
  .page-state {
    animation: none;
  }
}
```

## 오류 알림의 자리

| 범위 | 자리 |
| --- | --- |
| 입력 하나 | 그 칸 곁 |
| 양식 저장 | 양식 위 배너(`role="alert"`), 입력은 지킵니다 |
| 페이지 전체(변경 실패·충돌·읽기 전용) | 머리 아래 배너 줄 |
| 화면에 결과가 보이지 않는 짧은 완료(주소 복사, 보관, 백그라운드 작업 시작) | 토스트. 되돌릴 수 있으면 "되돌리기" 하나를 두고 충분히 오래 남깁니다. 오류·경고·되돌릴 수 없는 결과·다음 행동이 필요한 내용은 토스트에 두지 않습니다. 결과가 화면에 바로 보이면 알리지 않습니다. 토스트는 대화상자와 그 오버레이보다 위 층에 떠, 대화상자 안에서 한 동작의 결과가 오버레이 뒤에 가려지지 않습니다 |
| 상세에서 저장 버튼 없이 바로 저장되는 속성 변경(상태·담당·날짜·라벨·우선순위 등) | 결과가 화면에 보여도 "되돌리기" 토스트를 5초 띄웁니다. 토스트 아래 2px 막대가 남은 시간만큼 줄어들고 포인터가 올라가 있으면 멈춥니다. 되돌리기는 서버 최신본을 다시 읽은 뒤 바꾼 속성만 이전 값으로 저장해, 그 사이 다른 사람의 변경을 덮지 않습니다 |
| 화면을 그릴 수 없는 오류 | 라우트 오류 화면과 다시 시도 |
