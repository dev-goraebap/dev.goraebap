## 늘 챙기는 마감

컴포넌트와 레이아웃만으로는 채워지지 않는 스크롤, 화면 전환, 흔들림 방지 같은 마감 기준을 정리합니다. 정해진 정답은 아니지만, 웹 프로젝트를 만들 때마다 늘 챙기는 부분들입니다.

화면을 옮길 때의 대기와 전환, 처음 들어오거나 새로고침할 때의 첫 화면, 대화상자 안의 로딩과 높이 변화, 빈 상태와 실패 화면, 휴대폰에서 바뀌는 표면과 조작, 화면 크기와 스크롤바를 차례로 다룹니다. 화면의 모양과 컴포넌트 조합은 Design System, 라우트의 데이터 준비와 상태 소유는 Engineering에 둡니다.
