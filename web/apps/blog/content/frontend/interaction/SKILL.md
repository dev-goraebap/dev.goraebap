# 인터랙션

화면이 사용자 입력과 데이터 대기에 어떻게 반응하고 움직이는지를 다룹니다. 모양과 컴포넌트 조합은 [디자인 시스템](../design-system/SKILL.md), 라우트 데이터 준비·URL·상태 소유는 [프론트엔드 엔지니어링](../engineering/SKILL.md)이 맡습니다. 같은 규칙을 두 곳에 복제하지 않고 연결합니다.

## 예시

구현 모양은 각 자료 폴더의 스택 글(`react.md`·`angular.md`)에서 프로젝트 스택의 것만 읽습니다.

## 읽을 자료

- [페이지 전환과 대기](page-transition/index.mdx): 화면 전환, 진행 표시, 움직임의 시간과 동작 줄이기를 다룰 때 읽습니다.
- [로딩과 크기 전환](loading-feedback/index.mdx): 입력 디바운스, 대화상자의 데이터 준비, 높이 전환, 사진 자리를 다룰 때 읽습니다.
- [초기 진입과 새로고침](initial-load/index.mdx): 폰트 로딩, 스플래시 화면, 빌드 때 넣는 첫 화면을 다룰 때 읽습니다.
- [라우팅 마스크](route-masking/index.mdx): 목록 위 대화상자와 대상 주소, 새로고침·휴대폰 전환을 다룰 때 읽습니다.
- [화면 상태](ui-states/index.mdx): 빈 상태·결과 없음·없는 대상·실패 화면과 오류 알림의 자리를 다룰 때 읽습니다.
- [적응형 UI](adaptive-ui/index.mdx): 휴대폰 표면 고르기, 누르는 대상, 선택 칸, 키보드, 순서 바꾸기를 다룰 때 읽습니다.
- [화면 크기와 rem](ui-size.mdx): 큰 화면 자동 확대, 사용자 화면 크기 설정, rem과 px을 다룰 때 읽습니다.
- [스크롤바](scrollbar.mdx): 스크롤바 거터, 얇은 스크롤바, 부드러운 스크롤을 다룰 때 읽습니다.

완료 시 바뀐 화면의 데스크톱·휴대폰에서 대기·실패·빈 상태, 뒤로가기·새로고침, 포커스·키보드, 동작 줄이기 설정을 확인합니다.
