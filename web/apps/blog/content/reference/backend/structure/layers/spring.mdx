@Service
@RequiredArgsConstructor
public class BoardService {
    private final IssueColumnRepository issueColumnRepository;
    private final IssueRepository issueRepository;
    private final IssueProjects issueProjects;
    private final Clock clock;
    private final BoardQuery boardQuery;

    @Transactional(readOnly = true)
    public List<BoardViews.ColumnView> workspaceColumns() {
        return boardQuery.workspaceColumns();
    }
    // …
    @Transactional
    public void edit(CurrentUser user, String key, UUID columnId, BoardRequests.ColumnInput request) {
        var project = issueProjects.administered(user, key);
        var column = columnOf(project.id(), columnId);
        boolean closed = column.category().closes();
        column.revise(request.name(), request.category());
        var now = clock.instant();
        issueColumnRepository.saveAll(List.of(column), user.id(), now);
        if (closed != column.category().closes())
            issueRepository.updateClosedByColumnId(
                    column.id(), column.category().closes(), now);
        issueProjects.signal(project);
    }
    // …
}
```

`BoardService`는 클래스에 트랜잭션을 달지 않고 읽기 메서드에 `@Transactional(readOnly = true)`, 쓰기 메서드에 `@Transactional`을 붙입니다. 읽기는 같은 피처의 조회 포트 `BoardQuery`로 화면 DTO를 받고, 쓰기는 저장소에서 꺼낸 `IssueColumn`의 `revise`를 부른 뒤 `saveAll`로 저장합니다. 현재 시각은 주입한 `Clock`에서 읽습니다.

public class IssueColumn {

    public static IssueColumn create(UUID id, UUID projectId, String name, ColumnCategory category, int position) {
        var column = new IssueColumn(id, projectId, null, null, position);
        column.revise(name, category);
        return column;
    }

    public static IssueColumn fromPersistence(
            UUID id, UUID projectId, String name, ColumnCategory category, int position) {
        return new IssueColumn(id, projectId, name, category, position);
    }
    // …
    public void revise(String name, ColumnCategory category) {
        String next = name == null ? "" : name.strip();
        if (next.isEmpty() || next.length() > NAME_MAX) throw new DomainRuleViolation("상태 이름은 1~32자입니다");
        if (category == null) throw new DomainRuleViolation("상태의 분류를 골라 주세요");
        this.name = next;
        this.category = category;
    }
    // …
}
```

새로 만들 때는 `create`가 `revise`로 입력을 검증하고, 저장소가 읽어 올 때는 `fromPersistence`가 검증 없이 복원합니다. 업무 메서드는 모든 입력을 확인한 뒤에 상태를 바꾸고, 규칙 위반은 프레임워크에 기대지 않는 `DomainRuleViolation`으로 던집니다.
