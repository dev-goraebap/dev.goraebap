goraebap-workflow 플러그인이 에이전트에게 주는 개발 지침을 사람이 읽기 쉽게 모았습니다. 지침 문서는 플러그인의 원본 Markdown을 그대로 보여 주므로, 플러그인을 고치면 이 사이트도 함께 바뀝니다.

- [작업 방식](/rules/goraebap-mode/): 기능·버그·구조 변경을 어떤 순서로 하는지
- [프론트엔드](/rules/frontend/)·[디자인 시스템](/rules/design-system/): React 화면의 상태·구조와 화면 표현
- [백엔드](/rules/backend/)·[API](/rules/api/)·[데이터베이스](/rules/database/)·[아키텍처](/rules/architecture/): 서버와 계약, 스키마, 시스템 경계
- [프로젝트 연결](/rules/manage-workflow/): 프로젝트가 이 지침을 따르게 하고, 프로젝트만 다르게 하는 규칙을 적는 법
- [화면 해설](/app-shell/overview/)·[견본](/catalog/playground/): 화면 규칙의 배경과 실제로 조작해 보는 화면
