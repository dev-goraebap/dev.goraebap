# 라우팅 마스크

## 목록 위 대화상자와 대상 주소

목록에서 항목을 볼 때 데스크톱에서는 목록 맥락을 유지한 채 빠르게 훑고 싶지만, 대화상자만 띄우면 주소 공유와 새로고침이 깨집니다. 라우팅 마스크를 쓰면 데스크톱은 목록 위 대화상자와 대상 주소를 함께 유지하고, 휴대폰이나 직접 주소 진입 때는 대상 페이지 전체로 엽니다.

자기 주소가 있는 상세·작성·수정을 데스크톱 목록 위 대화상자로 엽니다. 목록은 그대로 두고 주소창에는 대상의 실제 주소를 보입니다. 어떤 리소스를 이렇게 여는지는 디자인 시스템의 [리소스 화면 패턴](../../design-system/resource-patterns/index.md)이 정하고, 이 글은 주소 계약을 정합니다. 상태·복귀와 직접 링크의 코드 계약은 Engineering의 [리소스 주소](../../engineering/resource-routes/index.md)가 소유합니다. 구현은 패널 열기·읽기, 대화상자 바꿔 끼우기, 크게 보기의 초안 넘기기를 공용 층 한 곳에 둡니다.

| 진입 | 결과 |
| - | - |
| 데스크톱 목록에서 열기 | 목록 주소에 패널 쿼리(예: `?panel=대상`) + 대상 주소 마스크, 대화상자 |
| 직접 링크·새로고침(새로고침하면 마스크를 풉니다) | 대상 페이지 |
| 휴대폰에서 열기, 휴대폰 폭에서 남은 패널 쿼리 | 대상 페이지 |
| 페이지로 열기(크게 보기) | 대상 페이지로 바꿔 갑니다(replace). 초안이 남습니다 |
| 대화상자 안에서 다른 대상으로 이동(상세 → 수정, 상세 → 다른 상세) | 같은 마스킹 이력을 replace하고 대화상자는 닫지 않고 자리를 이어받습니다 |
| 닫기·배경·Esc | 내부 이동 횟수와 관계없이 창 전체를 닫아 처음 연 목록의 조건·스크롤로 복귀. 처음 연 이력이 없으면 패널만 뺀 목록 |
| 저장 성공 | 결과 페이지로 바꿔 갑니다(replace). 뒤로 가면 목록 |

휴대폰에서는 마스킹을 끄고 일반 페이지 이동으로 엽니다. 그러면 브라우저 뒤로가기만으로 목록에 돌아옵니다.

스택별 구현: [react.md](react.md#open-masked) · [angular.md](angular.md#open-masked)의 「open-masked」 절

## 전역 검색과 폼에 적용하기

목록 위 대화상자는 Routed Modal 리소스의 상세·작성·수정과, 프로필 같은 짧은 보기, 전역 검색에 씁니다. 자기 페이지가 없는 짧은 양식(이름 바꾸기, 폴더 만들기)은 마스킹 없이 [짧은 양식 대화상자](../../design-system/dialog/index.md)로만 엽니다.

전역 검색이나 폼을 대화상자나 바텀시트로만 만들면 고유 주소가 없어 새로고침하거나 링크를 공유할 때 작업 맥락이 끊깁니다. 길이와 관계없이 자기 주소를 가진 페이지를 원본으로 두고, 환경에 따라 열기 방식만 나눕니다. 데스크톱에서는 지금 화면 위 대화상자로 열고 주소만 대상 페이지로 바꾸며, 새로고침하거나 페이지로 보기를 누르면 전체 페이지로 전환합니다. 휴대폰에서는 바텀시트 없이 처음부터 대상 페이지로 이동합니다.

스택별 구현: [react.md](react.md#search-and-forms)의 「search-and-forms」 절

## 확인할 동작

목록에서 열기 → 초안 입력 → 페이지로 열기 순서로 조작해 마스크 주소·실제 주소·초안 보존을 확인합니다. 상세에서 수정으로 넘어갈 때 대화상자가 닫혔다 열리지 않는지, 닫기·뒤로·앞으로와 직접 진입, 휴대폰 전체 화면을 확인합니다. 브라우저 주소·새로고침·링크 공유는 제품의 실제 주소에서 따로 검사하고 기록을 구분합니다.
