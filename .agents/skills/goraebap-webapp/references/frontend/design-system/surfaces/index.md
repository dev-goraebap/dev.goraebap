# 면과 경계

화면은 네 단계의 면으로 쌓습니다. 안쪽에 놓이는 면은 바깥보다 한 단계 위입니다. 같은 단계의 면을 겹치면 경계가 사라지므로 카드 안에 같은 카드를 넣지 않습니다.

| 단계 | 쓰임 | 표현 |
| - | - | - |
| 바닥 | 사이드바와 페이지가 놓이는 앱 바탕 | 사이드바 바탕 토큰(셸 wash) |
| 페이지 | 작업 영역, 행, 표 머리 | 페이지 바탕 토큰 |
| 올린 면 | 설정 묶음·카드·첨부 칸 | 카드 토큰, 내부 구분선 토큰의 테두리, 16px squircle |
| 뜬 면 | 메뉴·팝오버(12px)·대화상자(16px) | 팝오버 토큰, 가는 테두리(글자 10%), 메뉴·팝오버는 중간 그림자, 대화상자는 배경 막 |

inset 배치의 페이지 면은 페이지 바탕색이라 그 위의 카드가 한 단계 밝게 섭니다. 테두리로 직접 그린 상자는 올린 면으로 칠합니다. 모든 자식을 카드로 감싸지 않습니다. 목록 항목은 카드가 아니라 행이고, 카드는 독립된 묶음에만 씁니다.

## 선

선은 1px 테두리(`border`)로 그립니다. 내부 구분선과 바깥 경계는 [테마](../theme/index.md)의 두 토큰으로 나눕니다. 목록의 마지막 행 아래 구분선은 바깥 테두리와 겹치지 않게 지우고, 페이지 목록은 행이 있을 때만 끝에 한 줄을 둡니다. 카드의 마지막 구분선도 테두리와 겹치지 않게 합니다.

## 그림자와 모서리

그림자는 뜬 면에만 둡니다. inset 페이지 면에는 면 그림자 토큰(아주 옅은 그림자와 가는 외곽선) 하나를 둡니다. 팝오버·메뉴는 중간 그림자와 가는 테두리(1px, 글자 10%)를 씁니다. 대화상자는 그림자 대신 가는 테두리와 배경 막으로 구분합니다. 보드 카드처럼 페이지 위의 면에는 그림자 없이 면과 선으로 구분합니다.

| 대상 | 모서리 |
| - | - |
| 입력 칸·작은 요소 | 8px |
| 팝오버 | 12px |
| 카드·inset 페이지·대화상자 | 16px squircle |
| 메뉴 항목 | 10px squircle |
| 셀렉트 | 10px |
| 모든 버튼(만들기·도구 포함)·라벨(Token)·칩 | 완전한 둥근 모양 |

라벨은 둥근 칩이라 버튼처럼 보이지 않습니다. 같은 화면에 12px과 16px 카드를 섞지 않습니다.

## 점 무늬

일반 페이지(목록·설정)는 페이지 틀 바탕에 점 무늬 유틸리티 하나를 둡니다. List-Detail 화면은 고르기 전의 빈 오른쪽 칸에만 점 무늬를 둡니다([리소스 화면 패턴](../resource-patterns/index.md#list-detail)). 글자색 12%의 1px 점이 16px 간격으로 찍힙니다. 행과 카드는 불투명해서 점은 빈 여백과 상태 화면에만 보입니다. 상세·작성·대화상자·패널·달력처럼 내용 자체를 읽거나 쓰는 면은 평평하게 둡니다. 페이지마다 점 무늬를 켜고 끄지 않고 이 기준을 따릅니다. 끌어서 움직이는 캔버스는 더 진한 점(16%)으로 구분합니다.
