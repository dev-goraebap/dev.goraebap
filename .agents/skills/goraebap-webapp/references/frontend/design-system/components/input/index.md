# Input

이름, 이메일, 검색어처럼 한 줄의 짧은 텍스트를 입력받을 때 씁니다. 항상 부모 너비를 채우며, 유효성 검사 실패 시 오류 테두리와 접근성 상태를 함께 표시합니다.

스택별 구현: [react.md](react.md#usage) · [angular.md](angular.md#usage)의 「usage」 절

## 접근성

| 키 | 동작 |
| - | - |
| Tab | 다음 입력 칸이나 조작 요소로 포커스를 이동합니다. |
| Shift+Tab | 이전 입력 칸이나 조작 요소로 포커스를 이동합니다. |

- 모든 입력 칸에는 label 요소를 연결하거나 aria-label로 접근 가능한 이름을 제공합니다.
- 유효성 검사 오류는 테두리 변화만으로 알리지 말고 원인과 수정 방법을 담은 오류 문구를 함께 둡니다.
- disabled는 포커스와 폼 제출에서 빠지고, readOnly는 포커스와 폼 제출을 유지한 채 편집만 막습니다.

## 관련 컴포넌트

- [Textarea](../textarea/index.md): 설문 답변이나 메모처럼 여러 줄의 긴 글을 입력받을 때 씁니다.
- [Combobox](../combobox/index.md): 직접 입력으로 후보를 검색해 목록에서 값을 고를 때 씁니다.
- [OTP Field](../otp-field/index.md): 인증번호처럼 자릿수가 고정된 코드를 칸마다 나누어 입력받을 때 씁니다.
