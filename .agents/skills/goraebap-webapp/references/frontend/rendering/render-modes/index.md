# 렌더링 방식

## 업무 화면은 브라우저에서, 공개 페이지는 정적 생성

기본은 브라우저에서 그리는 방식(CSR)이며 빌드한 정적 파일로 배포합니다. 로그인 뒤에만 보이는 업무 화면은 검색 노출이 필요 없으므로 서버 렌더링을 두지 않습니다.

검색 노출이나 첫 화면 속도가 필요한 공개 페이지(랜딩·문서)는 빌드 때 HTML을 만드는 정적 생성(SSG)을 먼저 검토합니다. 정적 파일 배포를 그대로 쓸 수 있기 때문입니다. 요청마다 서버에서 그리는 렌더링(SSR)은 요청마다 내용이 달라지는 공개 화면처럼 정적 생성으로 풀리지 않는 구체적인 요구가 있을 때만 들이고, 그때는 운영할 서버와 배포 방식을 함께 정합니다(프로젝트 지침).

| 화면 | 렌더링 | 배포 |
| - | - | - |
| 로그인 뒤 업무 화면 | CSR | 정적 파일 |
| 랜딩·문서 같은 공개 페이지 | SSG를 먼저 검토 | 정적 파일 |
| 요청마다 달라지는 공개 화면 | SSR (요구가 있을 때만) | 운영 서버 필요 |
