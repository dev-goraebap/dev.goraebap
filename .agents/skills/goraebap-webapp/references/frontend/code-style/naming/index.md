# 파일과 이름

## 파일과 이름 규칙

파일 배치와 공개 API는 [화면 계층](../../structure/layers/index.md)을 따릅니다. 컴포넌트는 파일 하나에 하나씩 두고, 페이지 컴포넌트는 이름만 보고 페이지인지 알 수 있게 Page를 붙입니다. 파일 이름의 대소문자와 접미사는 스택의 공식 스타일 가이드를 따르고 한 프로젝트 안에서 섞지 않습니다.

스택별 구현: [react.md](react.md#naming) · [angular.md](angular.md#naming)의 「naming」 절

라우트 묶음 폴더, 경로 별칭, 린트 규칙은 프로젝트마다 다를 수 있으므로 작업 전에 현재 프로젝트 설정을 먼저 확인하고, 다른 프로젝트의 페이지 그룹이나 도우미 함수가 있다고 가정하지 않습니다.
