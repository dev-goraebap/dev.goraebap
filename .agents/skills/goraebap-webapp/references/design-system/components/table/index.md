# Table

여러 항목의 속성을 행과 열로 나란히 비교하거나 정렬·스캔해야 할 때 씁니다. 높은 밀도로 구조화된 데이터를 빠르게 훑어보는 목록 화면에 적합합니다.

스택별 구현: [react.md](react.md#usage) · [angular.md](angular.md#usage)의 「usage」 절

## 구성

| 부분 | 역할 |
| - | - |
| Table | 가로 스크롤 래퍼와 표 본체를 함께 렌더링하는 최상위 컨테이너입니다. |
| TableHeader | 열 제목 행을 묶는 헤더 영역입니다. |
| TableBody | 실제 데이터 행들을 담는 본문 영역입니다. |
| TableRow | 하나의 항목을 가로 한 줄로 표현하는 행입니다. |
| TableHead | 각 열의 이름과 정렬 기준을 나타내는 헤더 셀입니다. |
| TableCell | 개별 데이터 값을 표시하는 본문 셀입니다. |

## 접근성

- 표의 주제를 알 수 있도록 caption을 두거나 주변 제목과 aria-labelledby로 연결합니다.
- 열·행 헤더 셀에는 scope 속성을 명시해 스크린 리더가 셀과 헤더의 관계를 읽게 합니다.
- 데이터가 없을 때는 빈 표 대신 원인과 다음 행동을 담은 빈 상태를 보여 줍니다.
