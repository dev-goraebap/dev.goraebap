# Switch

알림 수신이나 기능 활성화처럼 켜짐과 꺼짐을 즉시 반영하는 설정에 씁니다. 별도 저장 버튼 없이 누르는 순간 상태가 바뀌는 항목에 어울립니다.

스택별 구현: [react.md](react.md#usage) · [angular.md](angular.md#usage)의 「usage」 절

## 접근성

| 키 | 동작 |
| - | - |
| Tab | 스위치로 포커스를 이동합니다. |
| Space | 켜짐과 꺼짐 상태를 전환합니다. |
| Enter | 켜짐과 꺼짐 상태를 전환합니다. |

- 스위치 옆의 설정 문구를 label로 연결해 접근 가능한 이름과 터치 영역을 함께 확보합니다.
- 비활성 상태일 때는 왜 바꿀 수 없는지 주변 설명으로 함께 알립니다.

## 관련 컴포넌트

- [Checkbox](../checkbox/index.md): 여러 항목을 고르거나 폼 제출 시 함께 저장하는 선택에는 Checkbox를 씁니다.
- [Toggle](../toggle/index.md): 툴바에서 굵게·정렬처럼 버튼 형태로 상태를 켜고 끌 때 씁니다.
